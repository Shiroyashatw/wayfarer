# ARPG 原型（0.0.1）

桌機的即時動作原型，用來試手感：能不能從《dungeonPOE》的自動戰鬥轉成 ARPG。純靜態網頁，`python3 -m http.server` 後開 `index.html`。

## 想給玩家的樂趣（MDA）
- **打擊感**：每一下都有回饋，包括畫面停頓（暴擊停更久）、震動、擊退、閃白、跳數字、火花。
- **閃避的緊張**：怪物出手前地上有紅色預警。在出手瞬間翻滾會觸發**見切**：時間變慢，下一擊必定暴擊。
- **掉寶的期待**：照 PoE 的做法，地上的名字框用稀有度上色，稀有裝備有光柱；放在背包裡的裝備會顯示換上後的數值變化（▲▼）。

## 操作
WASD 移動、滑鼠瞄準；左鍵斬擊（按住連砍，打中回魔力）、右鍵飛刃（穿透）、Q 旋風斬、E 居合突進（衝刺中無敵）；空白鍵翻滾、1 喝藥水（殺怪補充）、F 撿東西、I 背包、H 隱藏操作說明。

## 內容
- 一張洞窟地圖：15 群怪物，每 4 群有一隻菁英。
- 5 種小怪，各有自己的出手方式：史萊姆近戰、流浪狗撲咬、蝙蝠成群、鬼火遠程、黑熊砸地。
- 王是虎姑婆，招式有衝撞、連續砸地、叫蝙蝠、近身揮爪，半血以下會發狂。打倒後走進傳送門，進入下一層（怪物更強，物品等級更高）。
- 7 個裝備欄位，裝備分普通、魔法、稀有，詞綴隨物品等級變強；角色有等級。存檔放在 localStorage（`arpg_demo_v1`）。

## 檔案
| 檔案 | 內容 |
| --- | --- |
| `js/data.js` | 玩家、技能、翻滾與見切、怪物、王、裝備欄位、詞綴 |
| `js/game.js` | 存檔、裝備產生、角色數值 `stats`、地圖 `newArea`、玩家與技能 `useSkill`／`actHit`、翻滾 `doRoll`、受傷與見切 `hurtPlayer`、打怪 `hitMob`、怪物 AI `updMobs`、王 `bossAI`、主迴圈 `frame` |
| `js/render.js` | canvas 畫面：地板、預警、怪物、武士攻擊動畫、特效、跳數字、掉落標籤、光照、小地圖 |
| `js/hud.js` | HUD、裝備面板、說明框、死亡與通關卡片、輸入 |
| `js/audio.js` | 合成音效 |
| `tools/atlas.py` | 從 `../dungeonPOE` 的大圖挑出要用的圖，拼成 `img/atlas.png` 與 `js/art.js`（只有換圖時要跑，遊戲本身不依賴上一層） |
