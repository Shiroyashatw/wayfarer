# 塞令老師 平衡檢查

遊戲的廣度（各系有沒有東西）和深度（能不能組出 build）很容易在加新東西時漏掉某一系。**每次改內容或數值都跑一次，不要只看自己剛加的那一系。**

## 什麼時候用

- 新增／修改道具（武器、輔助、藥劑、寵物、防具）、職業、核心、怪物、異常狀態
- 改經濟（起始金、收入、背包升級費用）、升階倍率、生命、回合表
- 使用者回報某系太強／太弱、某星級沒東西、怪太簡單、局太短

## 步驟

1. **開本機遊戲**（`.claude/launch.json` 的 `wayfarer`），網址用 `http://localhost:8000/?p=2&v=任意字`（`v` 換一個值可以避開快取；**改了 JS 但版本號沒變，瀏覽器會用舊檔**）。
2. **載入檢查腳本**（javascript_exec）：
   ```js
   eval(await (await fetch('/.claude/skills/balance/balance.js')).text()); coverage()
   ```
3. **看靜態檢查**：最上面是問題清單。
   - ❌ 一定要修：主力星級（2～4★）沒武器、某系沒有輔助道具、職業沒起手道具或主打武器缺星級、核心太少、圖示不存在、說明出現 undefined／NaN／「+-」、怪物圖不存在。
   - ⚠️ 看情況：1★ 或 5★ 缺、只有 1 件輔助、異常沒有加成道具、圖示共用太多、防具／盾／藥水缺某星級。
4. **單件道具強度**（看有沒有某件道具太強／太弱；約 1～2 秒）：
   ```js
   itemPower()              // 全部道具：同星級同類別比，標出偏強（≥ 中位數 ×1.3）偏弱（≤ ×0.77）
   itemPowerOf('ragepotion') // 只看一件（改數值時前後比較用）
   ```
   做法：每件放進「標準背包」（兩把同星級搭檔武器＋一件防具，輔助道具配它指定標籤的武器、盾的輔助配盾、寵物的配寵物），看帶著它能打贏 ×N 倍強的「沒有它的同一個背包」（N 越大越強）。
   注意：標準背包只有 2 把武器，**「所有武器」類的加成會被低估**，數量越多越強的道具（例如所有武器攻速）要另外用 5～6 把武器的大背包、Ⅱ／Ⅲ 階再量一次。毒、流血這類持續傷害在「對手血量放大」的量法下會偏高，看到毒系偏強要對照實戰（`sims`）再決定。

5. **（快速）Node 版**：`node tools/pve_check.js 40 0.8` 印 PvE 勝率、對戰秒數、代打的名次（比瀏覽器快很多）；職業名次也可以直接在 Node 跑 `simLobby`（見 skill `bot-ai`）。

5b. **核心統計**（看哪個核心太常被選、哪個沒人要、哪些組合太強）：`node tools/core_stats.js 500 1300 --write` → `docs/核心統計.md`（每個職業的核心：三選一出現幾次、被選幾次、選擇率、拿著的平均名次；最常見與名次最好的「第一個＋第二個」組合）。選擇率很低的核心是機器人覺得沒用（可能真的弱，也可能 `botPower`／`botEcon` 沒算到它的效果，對照 skill `bot-ai`）；組合名次很好的要看是不是兩個效果疊起來太強。

6. **跑機器人模擬**（每次呼叫跑一批、會累積；一批太久會被 45 秒逾時切掉，所以分多次呼叫）：
   ```js
   await sims('class')   // 重複 4～5 次，累積到每職業約 50 個樣本
   await sims('pve')     // 重複 2 次
   await sims('fair')    // 重複 2 次
   report()
   ```
   改了數值要重測前先 `sims('reset')`。
7. **判讀**（目標值）：
   | 項目 | 目標 | 說明 |
   | --- | --- | --- |
   | 職業平均名次 | 2.9～4.1（6 人） | 公平是 (LOBBY_N + 1) / 2 = 3.5（0.1.29 起 6 人；4 人時 2.15～2.85）；每職業 50 個樣本時 ±0.4 都可能是誤差，要看兩輪以上再調 |
   | 野怪（1-1～1-3、2-2） | 95% 以上 | 太低新手會卡 |
   | 菁英 | 80～95% | |
   | 首領（2-5、4-4） | 60～75% | |
   | 公平性：對戰勝率 | 約 50% | 偏離 60% 以上代表機器人對局（產生對手快照）和玩家的規則不一樣，要查 `simLobby` |
   | 公平性：平均名次 | 3.2～3.8（6 人） | |
   | 一局回合數 | 40～50（6 人） | 0.1.29 生命 50、6 人時大約 7～9 階段（4 人、生命 40 時 22～28） |
| 對戰秒數 | 6 秒以上 | 太短（0.1.18 量到 3～4 秒）會變成純比爆發，慢速武器、回復、持續傷害、疲勞都沒作用 |
   | 背包格數 | 1-4 約 12、2-4 約 16～20、3-4 約 20～25、4-4 約 26 | |
8. **修**：照問題改資料（`js/items.js` 的 `ITEMS`／`CLASSES`／`CORE_MAIN`、`js/run.js` 的 `MOBS`、`js/data.js` 的經濟），再回到步驟 2 重跑，直到沒有 ❌、⚠️ 都有理由。
9. **交差時**把 coverage 的問題清單、模擬的數字（改之前／改之後）寫給使用者。數值大改（升階倍率、生命、回合表、道具）要換 `GVER` 並重傳種子（`seedGhosts(160)`，見 CLAUDE.md）。

## 常見陷阱（之前踩過的）

- **「所有武器」類的加成**：在小背包看不出來，後期 5～6 把武器時會很強（血祭原本是永久所有武器攻速 +15%）；開頭幾秒的爆發在戰鬥很短時等於永久，要量對戰秒數。

- **機器人和玩家規則不一致**：機器人對局（`simLobby`）一開始沒算打贏的金幣與連勝，玩家對戰勝率變 69%。改經濟或戰鬥結算時，`finishFight` 和 `simLobby` 兩邊都要改。
- **對手快照凍結**：對手那局打完後一直沿用最後的快照，越後面玩家越穩贏。0.1.10～0.1.21 用「直接照生命結算」解決，但局會在中途突然結束（玩家回報是 bug）。0.1.22 起改成加時、打贏扣他血；0.1.23 起機器人種子的第 1 名會繼續買東西打到 8-7（`simLobby` 的 solo，快照標 `ot: 1`），真人快照才用 `OT_DMG`／`OT_HP`（`otGrow`）加素質。只要名次的統計傳 `simLobby(seed, rating, { short: 1 })` 省時間。調這兩個數字的目標：同牌階（q 0.6）平均名次約 2.5、加時勝率 40～50%。
- **合成變弱**：合成是自動的，Ⅱ／Ⅲ 階的基礎數值要 ≥ 3 件／9 件的總和（現在 ×3／×9），角色加成（fx）也要跟著升階（`fxT`）。
- **新欄位沒進說明**：加了新的效果欄位（`on`、`fx`、`pre`、加成 key）要同時改 `itemDesc`／`MODN`／`PREN`，不然說明會少字或出現 undefined。
- **新職業或新標籤**：要補 `CORE_P`、`CORE_MAIN`、起手道具 `st`、機器人偏好 `th`，以及至少 2 件輔助道具（`for: 標籤`）。
- **快取**：改了 JS 沒升版本號，手機和瀏覽器都可能用舊檔；上版一定要 `python3 tools/setver.py`。
