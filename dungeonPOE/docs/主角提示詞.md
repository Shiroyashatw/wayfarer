# 主角提示詞（PixelLab）

## 女忍者模板（還沒產）

用 PixelLab 的 **Create character**（一次產 8 個方向，之後用同一個角色做動作）。選項名稱以畫面上看到的為準。

| 項目 | 設定 |
| --- | --- |
| Size／Canvas | 64 |
| Directions | 8 |
| View | Low top-down（斜上方俯視） |
| Body type／Template | Humanoid |
| Outline | Single color black outline |
| Shading | Medium |
| Detail | Medium |

```
full body, whole figure from head to feet, small character centered with empty space around,
young female ninja heroine, no mask, face fully visible, confident gentle expression,
long black hair in a high ponytail tied with a red ribbon,
sleeveless short dark navy ninja top with red trim, bare shoulders and arms,
red sash belt, short pleated dark skirt, black fingerless gloves,
fishnet stockings, tabi boots with white shin wraps,
both hands empty, no weapon, relaxed neutral standing pose
```

- 不拿武器：武器另外畫成小圖疊在手上、跟著滑鼠轉，換武器不用重做動作。
- 模板挑定之後要產的動作（8 個方向）：Idle（待機）、Running（跑）、揮擊、施法（往前伸手）、Roll／Dodge（翻滾）、Hurt（受傷）、Death（倒下）。
- 圖好之前遊戲用武士（`av_musashi`）頂著：`js/render.js` 的 `HERO_SP`。
