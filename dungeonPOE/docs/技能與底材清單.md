# dungeonPOE 底材與技能清單（草案，0.2.5）

企劃書第 5 節（裝備與做裝）、第 6 節（技能寶石）要用的「有哪些東西」。標記：**有**＝程式已經有，**新**＝要做；「來源」是參考的 PoE 技能。第一批先做 ★ 的。

## 0. 從 PoE1、PoE2 各拿什麼

| | 拿什麼 | 為什麼 |
| --- | --- | --- |
| **PoE2** | **武器決定技能組**：矛的技能要拿矛、弓的技能要拿弓 | 只有一位主角，換武器＝換玩法；撿到好武器會想換一套打法 |
| PoE2 | **技能之間的連動**：一招造出狀態或地形，另一招來引爆（冰牆＋冰擊碎、破甲＋重擊、力量球、燃燒地面） | 5 個技能鍵不是 5 個獨立按鈕，而是一套連招；手動玩家打得更爽 |
| PoE2 | **每招定位清楚**：清怪、打王、位移、控制、增益各一種 | 5 格要取捨，每格都有理由 |
| PoE2 | 精魄、技能寶石的孔位（已在企劃第 6 節） | — |
| **PoE1** | **不綁武器的大類**：法術、召喚、陷阱地雷圖騰、光環、詛咒、傳令 | 讓玩法夠多元；法師、召喚師不用拿近戰武器 |
| PoE1 | **輔助的深度**：分叉、連鎖、回返、多重打擊、觸發類 | 同一招靠輔助玩出不同樣子，是做 build 的主要樂趣 |
| PoE1 | 覺醒輔助、傳令（殺怪觸發爆炸） | 刷到爽：清怪連鎖反應 |
| **避開** | PoE1 一堆「同一招換元素」、沒人用的技能 | 每招都要有獨特的玩法；元素不同只在「冰凍／點燃／感電」效果真的不同時才分 |
| 避開 | 太長的引導、複雜的觸發迴圈 | 即時動作要爽快；觸發類一律加內建冷卻 |

## 1. 已經定的事（2026-10-31）

1. **法術用寶石自己的傷害（照 PoE）**：法術傷害＝寶石等級的基礎傷害；法杖、魔杖給「法術傷害 %」與「法術技能等級 +1」。攻擊技能照舊吃武器傷害。拿刀放火球不會因為刀很好就很強。
2. **加閃避**：防具分護甲、閃避、能量護盾三系＋混合（護甲／閃避、護甲／護盾、閃避／護盾）。閃避＝有機率完全躲開攻擊（法術不能躲），跟翻滾、見切是不同層。
3. **雙手武器不能拿副手**：野太刀、矛、棍、弓、法杖是雙手；刀、短刀、魔杖是單手，可以配盾、法器；箭袋只有拿弓才能用。
4. **不做力量／敏捷／智慧屬性門檻**：用物品等級就夠了。
5. **第一批武器**：弓＋箭袋、法杖、魔杖、短刀獨立出來、野太刀獨立出來（加上已有的刀、矛、棍，共 8 種）。
