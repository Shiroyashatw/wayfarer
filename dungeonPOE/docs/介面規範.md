# dungeonPOE 介面規範

改介面（畫面、面板、HUD、互動、動畫、說明文字的排版、CSS）時照這份。設計判斷以 skill `apple-design` 為主，這份提供 dungeonPOE 實際在用的數值、元件與技術限制；操作規則在 `docs/企劃書.md` 第 9 節。（舊的《塞令老師》直式規範在 `封存/設計規範.md`，不適用。）

## 1. 平台與測試尺寸

- **桌機為主、手機為輔**。手機是**橫向**全螢幕（`body.touch`）。
- 每次改介面，四個尺寸都要截圖：
  - 桌機 **1440×900**、**1280×720**（面板不能超出畫面）。
  - 手機橫向 **844×390**、**667×375**（`node tools/touch_check.js 寬 高 [網址]`，要先開本機伺服器；瀏覽器模擬時寬度小於 768 才會切成手機模式）。
- 遊戲邏輯只透過 `mouseWorld()` 與移動方向拿輸入，技能、戰鬥程式裡不判斷是不是手機。

## 2. 變數（`css/style.css` 開頭的 `:root`）

只用變數，不在 JS 寫死顏色或字級。

| 類 | 變數 |
| --- | --- |
| 底色、面板、線、字 | `--bg`、`--panel`（半透明深色）、`--line`、`--tx`、`--dim` |
| 狀態色 | `--gold`、`--good`、`--bad`、`--warn`、`--blue`（文字用 `.c-gold`、`.c-good`、`.c-bad`、`.c-warn`、`.c-dim`） |
| 稀有度 | `--r0`（普通）、`--r1`（魔法）、`--r2`（稀有）、`--r3`（寶石青色）；框色用 `.r0`～`.r3` |
| 元素 | `--fire`、`--cold`、`--light`、`--chaos`（和 `js/data.js` 的 `ELC` 一致） |
| 字級 | `--fs-s` 12px、`--fs` 14px、`--fs-l` 18px；手機 HUD 的最小字 10px |
| 間距、圓角 | `--sp` 8px、`--rad` 6px |
| 格子 | `--cell`（背包一格的邊長，`resize()` 照螢幕設定） |
| 字型 | `--font`（Noto Sans TC） |

地圖卡的星級顏色（藍、黃、紫、橘、紅）在 `js/maps.js` 的 `STARS`，用 `--sc` 傳進卡片。

## 3. 元件（照用，不要每個面板自己做一套）

| 元件 | class | 規則 |
| --- | --- | --- |
| 面板 | `.panel`、標題列 `.ph`（`<b>` 標題＋`<span>` 說明＋關閉 `.x`） | 置中的面板（地圖台 `#pdev`、生成寶石 `#pgem`）寬 `min(…px, calc(100vw - 24px))`、高 `calc(100vh - 24px)`，內容超出就捲動 |
| 按鈕 | `.btn`、主要 `.btn.pri`、小 `.btn.mini` | 一個畫面最多一個 `.btn.pri`；按鈕上只寫動作；停用的按鈕在 `title` 寫原因 |
| 主要按鈕固定在底部 | `#pdev > .btn.pri { position: sticky }` | 手機橫向一屏放不下時，主要動作還是按得到 |
| 頁籤、分段選擇 | `.gkind`（上方分段）、`.gtab`（左側頁籤，手機改成橫向捲動） | 選中的加 `.on` |
| 卡片清單 | `.gcard`（圖示＋名稱＋說明＋按鈕）、`.mcard`（地圖卡） | 鎖住的加 `.lock`（半透明＋說明為什麼鎖） |
| 裝備欄、插槽 | `.eqs`（`data-eq`、`data-sock`），鎖住的格加 `.lock` | 空格寫欄位名稱 |
| 道具 | `.it.r0`～`.r3`（格子背包） | 點一下＝搬移或說明；拖曳跟手 |
| 說明框 | `#tip`、`itemTip`／`gemTip` | 桌機滑過出現；手機點一下出現說明＋動作 |
| HUD | 生命球、魔力球 `.orb`（能量護盾＝疊白 `.ward`；精魄＝魔力球左邊的弧 `.spir`）、技能列 `#bar`、狀態列 `#mech` | 文字用 `setT` 更新，不要每格重畫整個 HUD |

## 4. 互動與動畫

- **按下就有回饋**：可點的元件 `:active` 縮小（`transform: scale(0.95～0.97)`）。
- 面板出現：`pop`（置中面板）、`inL`／`inR`（左右面板），200ms、`cubic-bezier(0.23, 1, 0.32, 1)`；動畫不擋操作。
- **減少動態**：`@media (prefers-reduced-motion: reduce)` 只淡入淡出。
- 不靠 hover 傳達資訊（手機沒有 hover）。
- 不用 `backdrop-filter` 或大面積模糊（效能）。
- 戰鬥特效用 pixelfx 序列圖（`fxs()`，`js/fxsheets.js`）；遊戲畫面上的東西畫在 canvas，不做成 DOM。

## 5. 資訊量

- 清單只放圖示＋名稱＋一行說明；詳細的放說明框。
- 數量 0、不能用、還沒開放的收起來或標 `.lock` 並說明原因。
- 能用數字或顏色代替句子就不要寫句子（▲▼、框色、星級）。

## 6. 檢查

- 改完在第 1 節的四個尺寸截圖，看：面板沒有超出畫面、主要按鈕看得到、字不小於 10px、按鈕不重疊。
- 手機跑 `tools/touch_check.js`（搖桿、技能點／拖／取消、翻滾、面板不出畫面、點道具的動作、天賦樹點兩次與兩指縮放）。
- `.claude/skills/ui-design/audit.js` 是《塞令老師》版的檢查，dungeonPOE 的面板 id 不同，用之前要確認它量的東西還適用。
