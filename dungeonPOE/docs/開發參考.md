# dungeonPOE 開發參考（濃縮版）

設計新東西前先讀這份。它把 PoE1／PoE2 的研究濃縮成**我們的規則**；細節與來源網址在各份研究文件（最後一節）。最高原則在 `docs/設計原則.md`（第 0 節「底層先行」），底層的規則與數字在 `docs/企劃書.md` 7.2。

## 0.1 武器與技能體系（2026-11-02 定案）

依據：`PoE武器與底材.md`、`PoE技能體系.md`。原則：**每種武器＝一種玩法身分**，技能照「一招製造狀態、另一招收割」串起來；重複的體系合併，不做兩套做法。

**武器 18 種＋徒手**，全部列進武器表、底材照 PoE2 資料做齊。技能分兩批：PoE2 已開放的 10 種先照 PoE2 的技能組做；還沒開放的 8 種用 PoE1 的同類技能加上自己設計補。原本的刀、野太刀、短刀拿掉。

| 武器 | 體系（身分） |
| --- | --- |
| 單手錘、雙手錘 | 重擊、猛擊、餘震、碎裂地面、破甲、重暈 |
| 長棍 | 連擊數、力量球、冰晶 |
| 矛 | 近戰與投擲雙模、招架與失衡（矛自己的技能）、狂怒球 |
| 弓 | 元素箭、毒氣雲（可引爆）、可重複射擊、標記 |
| 弩 | 彈藥、手雷、迫擊砲、砲台 |
| 單手劍、雙手劍 | 物理連斬（快、多段、蓄段數一次放出；跟錘的慢而重單發區分）、元素打擊（劍招附上元素）、幻影（召出劍士分身一起出招） |
| 單手斧、雙手斧 | 擲斧、流血、戰吼 |
| 連枷 | 蓄力引導、旗幟 |
| 匕首 | **御劍**（刃類法術，參考修仙：召出飛劍環繞、疊層、一次射出；劍陣插地再引爆）、**伏擊**（翻滾或完美閃避後瞬移背刺、必定暴擊）、暴擊為主軸 |
| 爪 | 快速多段、擊中回血回魔、致盲 |
| 陷阱器 | 陷阱、地雷、機關（踩到才爆） |
| 護符（變身） | 熊、狼人、飛龍、植物、風暴、狼（夥伴） |
| 法杖、魔杖 | 元素法術、混沌、詛咒、屍體與幽魂 |
| 權杖 | 光環、骷髏、魔像、傳令 |
| 不限武器 | 法術（元素法術、灌注與殘留物；烙印、咒符之力（法印）0.2.11 刪掉，不做）、詛咒、標記、觸發與能量、圖騰 |

**異常不算體系**：每種武器都會有幾招帶異常（點燃、冰緩、感電、流血、中毒、破甲…），表上只寫「整套玩法圍繞它」的（例：斧＝流血）。

副手（2026-11-02）：**盾只有一種**（不分盾與輕盾），隱性給「舉盾」（還沒做，待做清單），所有單手武器都能配；**招架改成矛自己的技能**，不靠副手。法器配單手法系武器（魔杖、權杖）。箭袋只配弓。**權杖可以放副手**，配任何單手武器（例：單手錘＋權杖＝近戰帶光環）。雙手武器不能拿副手（弓可配箭袋）。**雙持**：爪、匕首、單手劍、單手斧可以兩手各拿一把同類武器，攻擊時兩手輪流出、攻速更快；錘、矛、連枷、魔杖、權杖不能雙持。

**防具與飾品**（照 `PoE武器與底材.md` 第 3、4 節）：每個部位（頭、胸、手、腳）分護甲、閃避、能量護盾三系，再加護甲／閃避、護甲／護盾、閃避／護盾三種混合，每部位每系 4～6 個底材，只有終局胸甲有隱性詞。戒指、護身符一個底材對一條隱性詞（抗性、生命、魔力、攻擊附加、施法速度、精魄、稀有度…）；腰帶 1～3 格護符欄＋一條隱性詞（生命、藥水、護甲）。

**不做**：變異（Vaal）技能；PoE1 的異變寶石（每顆技能都有異變版，大多很爛）——它的概念併進族裔寶石。

**輔助寶石**
- 照 PoE2 0.3 以後：每顆輔助有一個分類，**同一分類不能插在同一個技能上**，可以跨技能重複。
- 分級：I、II 在生成視窗做（II 要求的角色等級比較高）；**最高一級＝覺醒**，只從特定王掉落（之後做那個機制時一起做）。I、II、覺醒同一分類。
- **族裔寶石**：插上去會改變技能的玩法（取代異變寶石的概念），全角色同名限一顆；先做 5～6 種試水溫，只從特定機制掉落。

**技能用的底層新機制**：✅ 0.2.10 已全部做進 `js/mech.js`，規則在企劃書 7.3。

## 1. 數值量級（照 PoE2，已依我們的樹密度下修）

細節：`PoE天賦參考.md`、`天賦下修對照.md`。

- **小點**：一點只給一種東西。傷害類 +3%（PoE2 是 8～12%，我們的樹點得到的比例是 PoE2 的 2.3 倍，所以壓更低）、攻速 +1%、暴擊率提高 +6%、暴擊傷害加成 +4%、護甲／閃避／能量護盾 +8%。
- **大點**：主效果約小點的 2.5～3 倍，或「主效果＋條件／代價」。
- **生命**：不給 %（大點最多 3%）；生命靠裝備與幹道上的基礎能力點（+10 生命）。
- **更多（more）**：天賦大點幾乎不給（PoE2 984 個大點只有 4 個），留給輔助、昇華、基石。
- **直接減傷**：不給（只有召喚物可以有）。
- **基石**：「30～50% 更多／更少」一定配一個明顯的代價，放在路線末端。

## 2. 天賦樹的結構（防止沿同一主題一路點爆）

細節與 PoE2 的實測數字：`PoE天賦結構.md` 第 5 節（18 條規則）。

**形狀＝幹道＋小口袋**：
- **幹道**：過路點（我們用基礎能力點：+10 生命、+10 魔力、+20 護甲、+20 閃避、+8 能量護盾）組成，像十字路口，約佔全樹 16%。走到一個大點的路上約 2/3 是過路點。
- **叢集**：沿幹道每 1～2 個過路點岔出一個；一個叢集 ＝ 2～6 小點 ＋ 1～2 大點，平均約 5 點。小點至少 80% 同一條詞；大點 75% 是同主題放大、25% 是轉折（接到隔壁主題或加條件、代價），放在叢集最裡面。64% 的叢集是死路（點完退回幹道），叢集之間不直接相連。
- **主題排列**：同主題叢集至少隔 3 步，平均 5 步以上；同主題相連的點平均 ≤ 3、最多 12。用「區域權重抽樣＋距離排斥」，不是固定輪換。
- **區域**：6 個起點各佔 60°。集中型主題（護甲、格擋、閃避、能量護盾、投射物、法術、召喚、陷阱、圖騰、各武器、精魄光環）綁在 1～2 區；通用主題（生命、暴擊、元素、攻速、範圍、魔力冷卻）每區都有。由內到外：通用防禦 → 主體 → 專精（武器、單元素、召喚）與基石。
- **規模（1643 點時）**：約 270 個叢集、380 個大點、14 個基石、260 個過路點。
- **驗收**（產生器跑完要量）：叢集平均 3～4 小／1.3～1.5 大、死路 55～70%、大點在最遠端 ≥ 75%、同主題連續平均 ≤ 3／90% ≤ 6／最大 ≤ 12、最近同主題叢集 ≥ 5 步、起點到第一個大點 4～5 步。

**樹缺的**：每種武器類別都要有自己的專精叢集（PoE2「持某武器時」的大點約是通用大點的 1.5 倍）。主題清單要等第 2、3 層定了才定。

## 3. 職業與昇華的設計

細節、PoE1／Phrecia／PoE2 全部昇華與例子：`PoE昇華參考.md`。

**骨架**：8 點 ＝ 4 個大點 ＋ 4 個小點。一個昇華準備 6～8 個大點，玩家只能拿一半。從中央起點放出幾條主幹，「小點 → 大點 → 強化大點」；放一組三選一大點；可以有一個要多個前置的終極大點。小點給這個昇華主題的單一數值。

**好的昇華大點用這六種手法**（每個昇華至少要有一個 A、B 或 E，不能整棵都是 +x%）：

| 手法 | 意思 | PoE 例子 |
| --- | --- | --- |
| A. 新資源／新機制 | 一定是既有數值的另一種讀法 | 地獄火（反過來的魔力）、黑暗（延後扣的生命）、靈光（走路生成、攻擊消耗） |
| B. 改寫底層規則 | 基石式的取捨 | 有護盾時生命不變、物理一半轉火、毒疊更多層但更短 |
| C. 綁一種玩法並質變 | 讓某體系出現新行為 | 異常必定觸發、冰凍感電變成地面、圖騰數量 |
| D. 給技能 | 用通用效果包成按鈕 | 時間凍結、顯化武器、三個高等光環 |
| E. 更多但附代價 | 好處和代價一起寫在同一點 | 傷害更多 40% ↔ 受到的傷害提高；只能穿普通胸甲 |
| F. 特殊結構 | 三選一、終極大點、多一個欄位 | 季節誓約、Sacred Unity、多一個護符欄 |

**我們的限制**：
- 只有一位主角，「職業」只是昇華的分組，加上天賦樹的起點位置。職業不限制武器（設計原則第 2 節第 2 條）。
- 職業照「武器類別、技能體系、底層特色」來分，等第 2、3 層盤點完才定。
- 每個大點都要寫它用到哪個底層概念；底層沒有的，先加進底層（寫進企劃書 7.2）才能用。
