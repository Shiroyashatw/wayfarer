# dungeonPOE 企劃書（草稿 0.0.1）

> 草稿・2026-10-30。設計原則見 `docs/設計原則.md`（最高優先）。數值都是草案，做出來後用自動玩家模擬再調。

## 1. 一句話

背著背包下地城，用手牌在隨機地圖上走格子，背包裡的裝備就是你的戰鬥力（全自動戰鬥）；熱度越來越高、墮落十二生肖開始追殺你之前，帶著寶物撤離。死了全部失去，只有黑盒裡的東西保得住。

| 項目 | 內容 |
| --- | --- |
| 類型 | 撤離（extraction）＋背包構築＋牌組移動、單人 PvE |
| 平台 | 手機直式網頁（電腦也能玩），純靜態，沒有建置步驟 |
| 參考作品 | 逃離塔科夫等撤離遊戲（黑盒、跑刀）、Clank!（手牌移動、噪音壓力）、Backpack Battles（背包擺位）、Path of Exile（詞綴 T 級） |
| 前作 | 《塞令老師》（背包自動對戰）：沿用自動戰鬥、背包格子與相鄰、職業主機制、美術；《漫步勇者》：沿用詞綴 T 級、墮落十二生肖、台灣妖怪 |

### 跟《塞令老師》的差別

| 塞令老師 | dungeonPOE |
| --- | --- |
| 4 人淘汰、打別人的快照 | 單人下地城，只打怪物（小怪、菁英、王、生肖） |
| 回合表、商店刷新、合成升階 | 手牌走地圖；掉寶與城鎮商店；沒有升階，改成隨機詞綴 T1～T6 |
| 職業綁武器標籤 | 武器誰都能拿，職業主機制不看武器 |
| 一局結束就沒了 | 帶出來的進倉庫，下次帶下去；死了全部失去 |
| 賽制、主題池、羈絆、料理、反制道具 | 全部拿掉 |

## 2. 核心循環

```
城鎮（整理倉庫、買背包與白裝、重骰詞綴、點天賦、選職業與 2 個核心）
  → 下地城（手牌走格子、打怪、撿東西、熱度上升）
  → 撤離成功：東西進倉庫、拿經驗　／　愛心全碎：只留黑盒、拿經驗
  → 回城鎮
```

- **目標**：打倒每座地城最深處的王，解鎖下一座更深的地城。
- **長期累積**：倉庫裡的詞綴裝備、背包收藏、職業天賦（解鎖、強化核心）。
- **每一趟的風險**：背上去的背包和裡面的東西。

## 3. 地城

**A（樂趣）**：探索未知、規劃路線、「再走一格還是現在撤」的貪心。
**D（行為）**：依手牌規劃路線，繞去寶箱、避開打不過的菁英；熱度高了往撤離點跑。

### 3.1 結構

- 第一座地城 3 層。每層是一張 **15～20 格的隨機網路**（格子之間有連線，有些路要多花移動點、有些是單行道），先做小，之後再放大。
- 每層有：入口、樓梯（往下一層）、1～2 個撤離點；第 3 層最深處是王。
- 打倒第 3 層的王 → 解鎖下一座地城（怪物更強、掉更高 T）。
- 生成規則：所有格子都走得到；撤離點離入口至少 3 步；樓梯與王在離入口最遠的區域；不會生成走不到的格子（設計原則第 4 節第 6 條）。

### 3.2 格子種類

| 格子 | 內容 |
| --- | --- |
| 戰鬥 | 小怪 1～3 隻 |
| 菁英 | 菁英 1 隻（＋小怪），掉藍裝 |
| 寶箱 | 道具或金幣；開箱熱度 +2 |
| 商店（地城商人） | 用這趟撿的金幣買牌、藥水、白裝 |
| 事件 | 台灣民俗事件（土地公、紅包…，從《漫步勇者》肉鴿版挑），二選一 |
| 休息 | 回一部分生命 |
| 樓梯 | 下一層（生命延續，手牌重洗） |
| 撤離點 | 選擇撤離：帶著東西回城鎮 |
| 王 | 第 3 層最深處，打倒才解鎖下一座地城 |

開打的格子（戰鬥、菁英、王）走到就先顯示怪物資訊，再選「打」或「跑」（3.5）。

### 3.3 手牌移動（參考 Clank!）

- **起始牌組 10 張**：移動 1 ×5、移動 2 ×3、偵查（看相鄰 2 步內的格子內容）×1、喘息（回 15% 生命）×1。
- 每回合抽 5 張，打出任意張，移動點加總後自己決定怎麼走（可以在路上停下來處理格子）。回合結束沒打的牌棄掉，牌堆用完洗棄牌堆。
- **地城裡拿到的牌**（寶箱、事件、地城商人）只在這一趟有用，回城就沒了：大步（移動 3）、潛行（熱度 -3）、繞道（無視單行道）、伏擊（下一場戰鬥開場傷害 +30%）、撬鎖（寶箱多一件）、偵查遠方（看整層的撤離點）…
- **牌只管地圖上的選擇**，戰鬥強度一律看背包（伏擊這類牌只是暫時加成）。
- 牌組小、看得到牌堆與棄牌堆剩幾張，玩家能規劃（設計原則第 4 節第 3 條）。

### 3.4 熱度與墮落十二生肖（參考《漫步勇者》的狩獵）

**A**：壓力越來越大的緊張感。**D**：熱度 Ⅱ 時有人撤、有人賭；熱度滿後往撤離點跑。

- **熱度上升**：每回合 +1、每打一場 +3、開寶箱 +2、逃跑 +5；潛行類的牌可以降。換層不會歸零。
- **等級**（草案）：

| 等級 | 熱度 | 怪物 | 掉寶 |
| --- | --- | --- | --- |
| Ⅰ | 0～19 | 原本 | 原本 |
| Ⅱ | 20～39 | 生命、攻擊 +25% | 藍裝機率、T 上升 |
| Ⅲ（滿） | 40 | 生命、攻擊 +50% | 同 Ⅱ |

- **熱度滿了（Ⅲ）就不會再降**（潛行牌失效），**每 2 回合生出一隻墮落十二生肖**：
  - 第一隻出現在離玩家最遠的格子，之後每一隻都生得比上一隻近（最後會直接生在旁邊）。
  - 生肖每回合往玩家走 2 格，碰到就強制開打，**不能逃跑**（生肖代表縮圈）。
  - 地圖上一直顯示每隻生肖的位置與幾步會追到，下一隻什麼時候、大概生在哪裡也要預告（死亡要看得到原因）。
  - 生肖是首領級（比王稍弱、比菁英強很多），每隻帶 2 條詞綴（迅捷、堅韌、烈焰、冰霜、雷暴、吸血、狂暴、鐵甲）。
  - 打倒掉大量金幣＋1 件 T1～T2 詞綴裝備。第一版沒有印記與傳奇兌換。
- 十二生肖（名字沿用《漫步勇者》）：瘟噬鼠皇、獄鎖魔牛、血牙虎煞、月蝕狂兔、天墜邪龍、毒涎蛇姬、焚魂夢魘、魔羊祭司、雷魘猴王、業火冥雞、冥府獄犬、屠野魔豬。

### 3.5 逃跑

- 開打前選「跑」：退回上一格、熱度 +5、隨機棄掉一張手牌（沒手牌就不棄）。
- 一般怪、菁英、王都能跑；**生肖不能跑**。
- 已經開打就不能跑（戰鬥是全自動的）。所以開打前一定要看得到：怪物生命、攻擊、詞綴，以及「預估勝率」或強弱提示。

### 3.6 生命、愛心、死亡

- 生命值在戰鬥之間延續，靠喘息牌、休息格、藥水、核心回復。
- **每趟 3 顆愛心**：生命歸零碎一顆，原地回滿血繼續走（那場戰鬥算輸，那隻怪還在原地）。之後城鎮可以加愛心數。
- **3 顆全碎＝死亡，被抬出地城**：除了黑盒，**全部失去**——背包本身、裡面的裝備、這趟撿的金幣。
- 撤離與死亡都拿職業經驗（成功拿得多）。

## 4. 背包與黑盒

**A**：「我的擺法」的自我表達；「拿來打還是拿來保」的取捨。
**D**：好裝備在背包與黑盒之間猶豫；越大的包越捨不得死。

- **主背包**：放在裡面的裝備就是戰鬥數值，可以擺位、有相鄰加成（沿用《塞令老師》的 `bag.js`）。
- **背包在工坊買**：每種背包有自己的形狀與大小，買了進收藏，出發前挑一個背。**死了背包一起失去**，所以要一直花金幣；前期的背包便宜，越大越貴。

| 背包（草案） | 形狀 | 格數 | 價格 |
| --- | --- | --- | --- |
| 新手包 | 4×4 | 16 | 免費（沒背包時自動給） |
| 方形包 | 5×4 | 20 | 便宜 |
| 長條包 | 6×3 | 18 | 便宜 |
| L 形包 | L 形 | 22 | 中 |
| 十字包 | 十字形 | 24 | 中 |
| 大方包 | 5×5 | 25 | 貴 |

- **黑盒**：固定 3×3，**不參與戰鬥**，死了也不會失去。放在裡面的道具保證帶出來。
- **錢袋**：佔 1 格的道具，可以放進黑盒，裡面的金幣死了也保得住（不放在黑盒裡的錢袋跟著失去）。
- **跑刀**：倉庫裡沒有背包或沒有裝備時，出發一律免費給新手包＋木劍＋皮甲，保證隨時能再下去。
- 之後：城鎮的裁縫師可以在背包上縫特殊格（例：這格的武器攻速 +20%）。

## 5. 道具與詞綴

**A**：收藏好詞綴的爽感、為了好詞綴改擺法。
**D**：撿到高 T 會想辦法放進背包或黑盒；去鐵匠重骰。

### 5.1 道具（只有原始的武器與防具）

沿用《塞令老師》0.4.0 轉型時的原始道具（形狀、攻速、傷害、生命、護甲、格擋）。武器**誰都能拿**，沒有職業限制；★ 是底材等級，越深的層越容易掉高 ★。

| 類別 | 道具 |
| --- | --- |
| 武器（16） | 木劍、短刀、獵弓、木棒、鐵劍、火焰法杖、冰霜法杖、毒匕首、戰斧、雷霆錘、長槍、連弩、吸血鐮刀、屠龍大劍、鳳凰弓、天雷 |
| 防具（9） | 皮帽、皮甲、木盾、鐵盔、鐵盾、輕靴、鎖子甲、荊棘盾、聖騎士盾 |
| 其他 | 錢袋（第 4 節）、地城裡的藥水（消耗品） |

- 沒有升階、沒有合成；飾品、寵物、職業核心道具都不做（核心改成出發前裝備，第 6 節）。

### 5.2 詞綴

- **稀有度**：白（沒有詞綴）、藍（1 個前綴或 1 個後綴，或各一個）。第一版**每件最多一個前綴、一個後綴**。
- **T1～T6**，T1 最強（跟《漫步勇者》一樣）。越深的層、熱度越高，能掉到的 T 越高；生肖必掉 T1～T2。
- **前綴管數值**：傷害 %、附加物理、附加火焰／冰冷／閃電、生命、護甲、格擋…
- **後綴管機制**，混入《塞令老師》背包版的擺放效果：攻速、暴擊、吸血、燃燒／中毒／流血／凍結／感電機率、相鄰的武器傷害 +、放在背包角落時…、旁邊沒有東西時…、同一排都是武器時…
- 詞綴的原始表從《漫步勇者》肉鴿版挖（鋒利、沉重、灼熱、冰冷、雷鳴、健壯、堅固、精準、暴虐、吸血、迅捷、再生…），砍到適合 25 件道具的數量，再補背包效果的後綴。
- 有詞綴的道具名字照稀有度上色，說明一個效果一行，T 級寫在詞綴旁邊（例：`T2 鋒利　傷害 +30%`）。

### 5.3 異常狀態（第一版 5 種）

燃燒（持續傷害）、中毒（持續傷害，可疊層）、流血（持續傷害）、凍結（跳過下一下）、感電（受到傷害增加）。規則從《塞令老師》的 `異常清單.md` 挑，機率觸發一律用偽隨機 `prd`。

## 6. 職業、核心、天賦

**A**：第一趟就玩得到職業的特色；每一趟都在解鎖新東西。
**D**：每個職業都有人玩、核心組合有分歧；職業會偏好某些武器，但不是只能拿那些。

### 6.1 職業（第一版 5 個）

一開始就能選。每個職業有一個**不看武器標籤**的主機制（設計原則第 7 節），一開始就有；武器只影響疊得快慢。

| 職業 | 主機制 | 偏好 |
| --- | --- | --- |
| 浪人 | **架勢**：每次攻擊 +1 層，滿 5 層下一擊是居合（傷害 ×3） | 攻速快的武器 |
| 騎士 | **盾勢**：護盾每吃掉 20 點傷害 +1 層（最多 20），每層傷害 +2% | 防具、盾多 |
| 火法師 | **燃燒**：所有命中都疊燃燒層數，核心負責引爆 | 打很多下的武器 |
| 刺客 | **印記**：命中 +1 層，滿 8 層下一擊消耗：必定暴擊、每層 +5% | 暴擊、攻速 |
| 馴獸師 | **獸群**：開戰帶一隻戰狼，每攻擊 6 次再召喚一隻（最多 3 隻），核心強化獸群 | 攻擊次數多 |

- 主機制與核心沿用《塞令老師》（`docs/職業與核心.md`、`docs/騎士與刺客重製.md`），**拿掉跟武器標籤綁在一起的部分**。
- 之後再開放其他職業（狂戰士、弓箭手、亞馬遜、冰法師、雷法師、毒師、鍊金術士）。

### 6.2 核心

- 每個職業一開始送 1 個最簡單的核心。
- **出發前裝 2 個核心**（從已解鎖的挑），不占背包格子；死了不會失去。
- 核心分角色：製造、收割、續航、控制，兩個不同角色的核心要能相乘。
- 每個職業最後有 8～12 個核心。

### 6.3 天賦樹

- 每個職業一棵小樹，大約 20 個節點，三種節點：
  - **解鎖核心**：把一個新核心加進可裝備的清單。
  - **強化核心**：門檻變低、數值變高（例：架勢 5 層 → 4 層）。
  - **小數值**：生命、傷害等。
- **用那個職業出地城才拿那個職業的經驗**，撤離成功拿得多、死亡也拿（每一趟都有進度）。
- 在城鎮可以免費重點。
- 沒有昇華、沒有轉職。

## 7. 城鎮

| 建築 | 功能 |
| --- | --- |
| 倉庫 | 存帶出來的裝備；出發前從倉庫把裝備放進背包 |
| 商店 | 用金幣買白裝 |
| 鐵匠 | 花金幣重骰一件裝備的詞綴（前綴或後綴擇一） |
| 背包工坊 | 買背包（第 4 節） |

- 「背包夠強才能去更深」不做戰力門檻：**打倒那座地城的王才解鎖下一座**。
- 之後：裁縫師（背包縫特殊格）、增加愛心數的建築、更多地城。

## 8. 經濟（草案）

- **金幣來源**：戰鬥、菁英、王、生肖、寶箱、事件。地城裡撿的金幣死了全部失去（放在黑盒錢袋裡的除外）。
- **金幣去處**：背包工坊（主要的消耗，因為死了背包會失去）、商店白裝、鐵匠重骰、地城商人。
- 目標：一趟撤離成功的收入，大約夠買一個同級的背包＋幾次重骰；死一次會痛，但跑刀幾趟就能回來。

## 9. 怪物

**A**：強度差距看得見。**D**：打王前會整理背包、打不贏的會跑。

| 等級 | 生命、攻擊 | 特色 | 掉落 |
| --- | --- | --- | --- |
| 小怪 | ×1 | 沒有詞綴 | 金幣、白裝 |
| 菁英 | ×3 | 1～2 條詞綴（迅捷、堅韌、吸血…） | 藍裝 |
| 王 | ×10 | 專屬技能（召喚小怪、每 10 秒狂暴…） | 高 T 裝備、解鎖下一座地城 |
| 生肖 | 王的 ×0.7 左右 | 2 條詞綴，不能逃 | 大量金幣＋T1～T2 裝備 |

- 用台灣妖怪：從《漫步勇者》肉鴿版挖（牛頭、馬面、黑白無常、魔神仔、虎姑婆、陳守娘、椅仔姑、林投姐、水鬼、冥婚新娘、紅衣小女孩、吊死鬼…），美術沿用 `art/monsters/`。
- 第一座地城的王從這些首領裡挑一個。

## 10. 技術做法

- 資料夾 `dungeonPOE/` 自己就能跑（自己的 `index.html`、`css/`、`js/`、`img/`、`art/`、`docs/`、`tools/`、`CLAUDE.md`、`.claude/skills/`），以後可以整個搬到別的 repo。網址 `…/wayfarer/dungeonPOE/`。
- 從《塞令老師》複製再刪：`core.js`（工具、固定亂數）、`sim.js`（自動戰鬥）、`bag.js`（格子、相鄰、`compileBag`）、`audio.js`、`cloud.js`（只留存檔）、`sprites.js`、`tools/art.py`（美術打包）。
