# dungeonPOE 企劃書（0.1.0）

> 2026-10-30・0.1.0 第一版。設計原則見 `docs/設計原則.md`（最高優先）。數值用自動玩家（`node tools/autoplay.js`）模擬過，上線後看真人再調。

## 1. 一句話

背著背包下地城，用手牌在隨機地圖上走格子，背包裡的裝備就是你的戰鬥力（全自動戰鬥）；熱度越來越高、墮落十二生肖開始追殺你之前，帶著寶物撤離。死了全部失去，只有黑盒裡的東西保得住。

| 項目 | 內容 |
| --- | --- |
| 類型 | 撤離（extraction）＋背包構築＋牌組移動、單人 PvE |
| 平台 | 手機直式網頁（電腦也能玩），純靜態，沒有建置步驟 |
| 參考作品 | 逃離塔科夫等撤離遊戲（黑盒、跑刀）、Clank!（手牌移動、噪音壓力）、Backpack Battles（背包擺位）、Path of Exile（詞綴 T 級） |
| 前作 | 《塞令老師》（背包自動對戰）：沿用自動戰鬥、背包格子與相鄰、職業主機制、美術；《漫步勇者》：沿用詞綴 T 級、墮落十二生肖、台灣妖怪 |

### 跟《塞令老師》的差別

| 塞令老師 | dungeonPOE |
| --- | --- |
| 4 人淘汰、打別人的快照 | 單人下地城，只打怪物（小怪、菁英、王、生肖） |
| 回合表、商店刷新、合成升階 | 手牌走地圖；掉寶與城鎮商店；沒有升階，改成隨機詞綴 T1～T6 |
| 職業綁武器標籤 | 武器誰都能拿，職業主機制不看武器 |
| 一局結束就沒了 | 帶出來的進倉庫，下次帶下去；死了全部失去 |
| 賽制、主題池、羈絆、料理、反制道具 | 全部拿掉 |

## 2. 核心循環

```
城鎮（整理倉庫、買背包與白裝、重骰詞綴、點天賦、選職業與 2 個核心）
  → 下地城（手牌走格子、打怪、撿東西、熱度上升）
  → 撤離成功：東西進倉庫、拿經驗　／　愛心全碎：只留黑盒、拿經驗
  → 回城鎮
```

- **目標**：打倒每座地城最深處的王，解鎖下一座更深的地城。
- **長期累積**：倉庫裡的詞綴裝備、背包收藏、職業天賦（解鎖、強化核心）。
- **每一趟的風險**：背上去的背包和裡面的東西。

## 3. 地城

**A（樂趣）**：探索未知、規劃路線、「再走一格還是現在撤」的貪心。
**D（行為）**：依手牌規劃路線，繞去寶箱、避開打不過的菁英；熱度高了往撤離點跑。

### 3.1 結構

- 第一座地城 3 層。每層是一張 **15～20 格的隨機網路**（格子之間有連線，有些路要多花移動點、有些是單行道），先做小，之後再放大。
- 每層有：入口、樓梯（往下一層）、1～2 個撤離點；第 3 層最深處是王。
- 打倒第 3 層的王 → 解鎖下一座地城（怪物更強、掉更高 T）。
- 生成規則（`dungeon.js` 的 `genMap`）：6 排，第 0 排是入口、最上排有樓梯（第 3 層是王）；15% 的路是險路（要 2 移動點，虛線）、12% 往上的路是單行道（箭頭）；撤離點在第 2～4 排（1～2 個）。所有格子從入口都走得到、每一格都走得到樓梯或王（`tools/check.js` 每次檢查 300 張）。
- 看得到的範圍：入口、撤離點、樓梯、王一直看得到；其他格子要走到旁邊、或用「偵查」「遠望」才知道是什麼（「?」）。

### 3.2 格子種類

| 格子 | 內容 |
| --- | --- |
| 戰鬥 | 小怪 1～3 隻 |
| 菁英 | 菁英 1 隻（＋小怪），掉藍裝 |
| 寶箱 | 一個 3×3 的箱子（1～2 件）＋金幣；開箱熱度 +2 |
| 商店（地城商人） | 用這趟撿的金幣買藥水、錢袋、2 件裝備（放在地上） |
| 事件 | 台灣民俗事件（土地公、紅包…，從《漫步勇者》肉鴿版挑），二選一 |
| 休息 | 回一部分生命 |
| 樓梯 | 下一層（生命延續，手牌重洗） |
| 撤離點 | 選擇撤離：帶著東西回城鎮 |
| 王 | 第 3 層最深處，打倒才解鎖下一座地城 |

開打的格子（戰鬥、菁英、王）走到就先顯示怪物資訊，再選「打」或「跑」（3.5）。

### 3.3 移動（0.1.2 起：點了就走，像殺戮尖塔）

- 0.1.0～0.1.1 用手牌移動（參考 Clank!），玩家回饋「卡片效果不直覺，不知道怎麼用」，0.1.2 拿掉。
- 點相鄰、亮起來的格子就走過去；每走一步熱度 +1，險路（虛線）算 2 步。單行道（箭頭）只能照方向走。
- 走到旁邊的格子才看得到內容（「?」）；入口、撤離點、樓梯、王一直看得到。

### 3.4 熱度與墮落十二生肖（參考《漫步勇者》的狩獵）

**A**：壓力越來越大的緊張感。**D**：熱度 Ⅱ 時有人撤、有人賭；熱度滿後往撤離點跑。

- **熱度上升**（0.1.2）：每走一步 +1（險路 2）、每打一場 +3、開寶箱 +2、逃跑 +5；孟婆湯事件可以降。換層不會歸零。
- **等級**（草案）：

| 等級 | 熱度 | 怪物 | 掉寶 |
| --- | --- | --- | --- |
| Ⅰ | 0～34 | 原本 | 原本 |
| Ⅱ | 35～74 | 生命、攻擊 +25% | 藍裝機率、T 上升 |
| Ⅲ（滿） | 75 | 生命、攻擊 +50% | 同 Ⅱ |

- **熱度滿了（Ⅲ）就不會再降**，**之後每走 4 步生出一隻墮落十二生肖**：
  - 第一隻出現在離玩家最遠的格子，之後每一隻都生得比上一隻近（最後會直接生在旁邊）。
  - 你走 2 步，生肖往你走 1 格（比你慢，還跑得掉），碰到就強制開打，**不能逃跑**（生肖代表縮圈）。
  - 地圖上一直顯示每隻生肖的位置與幾步會追到，下一隻什麼時候、大概生在哪裡也要預告（死亡要看得到原因）。
  - 生肖是首領級（生命是小怪的 4.5 倍、攻擊 1.8 倍，再加熱度 Ⅲ 的 +50%），每隻帶 2 條詞綴（迅捷、堅韌、烈焰、冰霜、雷暴、吸血、狂暴、鐵甲）。
  - 打倒掉大量金幣＋1 件 T1～T2 詞綴裝備。第一版沒有印記與傳奇兌換。
- 十二生肖（名字沿用《漫步勇者》）：瘟噬鼠皇、獄鎖魔牛、血牙虎煞、月蝕狂兔、天墜邪龍、毒涎蛇姬、焚魂夢魘、魔羊祭司、雷魘猴王、業火冥雞、冥府獄犬、屠野魔豬。

### 3.5 逃跑

- 開打前選「跑」：退回上一格、熱度 +5。
- 一般怪、菁英、王都能跑；**生肖不能跑**。
- 已經開打就不能跑（戰鬥是全自動的）。所以開打前一定要看得到：怪物生命、攻擊、詞綴、**牠的背包**，以及**危險等級**。
- **危險等級**（0.1.2，`sim.js` 的 `danger`）：同一場用 8 個種子模擬，**不顯示勝率數字**（顯示 90% 卻輸了會很賭爛）：安全（綠，勝 95% 以上且剩一半血）、小心（黃，80% 以上）、危險（橘，40% 以上）、致命（紅）。

### 3.5.1 怪物的背包與戰利品（0.1.2）

- **A**：打贏的獎勵看得到、拿什麼自己決定。**D**：會為了某隻怪背包裡的好東西去打牠；背包滿了要取捨。
- 每場遭遇的帶頭怪物（和寶箱）都有自己的背包：小怪、寶箱 3×3（1～2 件）、菁英 4×4（2～3 件，至少一件藍裝）、生肖 4×4（T1～T2）、王 5×5（4 件＋藥水）。
- 背包裡的裝備**真的會讓帶頭的怪變強**（`dungeon.js` 的 `equipFoe`）：武器各自出手、防具加生命與護甲；牠本身的數值打 7 折，用裝備補回來。開打前可以點進去看每一件。
- 打贏（或開寶箱）後，牠的背包攤在地上（戰利品），把想要的拖進自己的背包或黑盒；走開就沒了。另外拿金幣。

### 3.6 生命、愛心、死亡

- 生命值在戰鬥之間延續，靠休息格（回 35%）、藥水、事件、核心回復。
- **每趟 3 顆愛心**：生命歸零碎一顆，原地回滿血繼續走（那場戰鬥算輸，那隻怪還在原地）。之後城鎮可以加愛心數。
- **3 顆全碎＝死亡，被抬出地城**：除了黑盒，**全部失去**——背包本身、裡面的裝備、這趟撿的金幣。
- 撤離與死亡都拿職業經驗（成功拿得多）。

## 4. 背包與黑盒

**A**：「我的擺法」的自我表達；「拿來打還是拿來保」的取捨。
**D**：好裝備在背包與黑盒之間猶豫；越大的包越捨不得死。

- **主背包**：放在裡面的裝備就是戰鬥數值，可以擺位、有相鄰加成（沿用《塞令老師》的 `bag.js`）。
- **背包在工坊買**：每種背包有自己的形狀與大小，買了進收藏，出發前挑一個背。**死了背包一起失去**，所以要一直花金幣；前期的背包便宜，越大越貴。

| 背包 | 形狀（寬×高） | 格數 | 價格 |
| --- | --- | --- | --- |
| 新手包 | 3×3 | 9 | 5（沒背包時免費送；0.1.3 起舊存檔的 4×4 也換回 3×3） |
| 方包 | 4×4 | 16 | 20 |
| 直筒包 | 3×5 | 15 | 30 |
| 腰包 | 5×3 | 15 | 30 |
| 長條包 | 6×3 | 18 | 70 |
| 登山包 | 4×5 | 20 | 90 |
| 方形包 | 5×4 | 20 | 90 |
| L 形包 | 5×5 缺右上 2×3 | 19 | 120 |
| T 字包 | 6×4，下兩排兩邊缺 | 20 | 140 |
| 十字包 | 5×5 缺四角 | 21 | 160 |
| 行軍包 | 4×6 | 24 | 200 |
| 寬口包 | 6×4 | 24 | 200 |
| 環形包 | 5×5 中間缺一格 | 24 | 220 |
| 大方包 | 5×5 | 25 | 300 |
| 遠征包 | 6×5 | 30 | 480 |
| 傳說行囊 | 6×6 | 36 | 750 |

- 「據角」詞綴的角落：形狀裡上下左右最多只有 2 個鄰格的格子，所以奇怪的形狀角落比較多。

- **黑盒**：固定 3×3，**不參與戰鬥**，死了也不會失去。放在裡面的道具保證帶出來。
- **錢袋**：佔 1 格的道具，可以放進黑盒，裡面的金幣死了也保得住（不放在黑盒裡的錢袋跟著失去）。
- **跑刀**：倉庫裡沒有背包或沒有裝備時，出發一律免費給新手包＋木劍＋皮甲，保證隨時能再下去。
- 之後：城鎮的裁縫師可以在背包上縫特殊格（例：這格的武器攻速 +20%）。

## 5. 道具與詞綴

**A**：收藏好詞綴的爽感、為了好詞綴改擺法。
**D**：撿到高 T 會想辦法放進背包或黑盒；去鐵匠重骰。

### 5.1 道具（只有原始的武器與防具）

沿用《塞令老師》0.4.0 轉型時的原始道具（形狀、攻速、傷害、生命、護甲、格擋）。武器**誰都能拿**，沒有職業限制；★ 是底材等級，越深的層越容易掉高 ★。

| 類別 | 道具 |
| --- | --- |
| 武器（16） | 木劍、短刀、獵弓、木棒、鐵劍、火焰法杖、冰霜法杖、毒匕首、戰斧、雷霆錘、長槍、連弩、吸血鐮刀、屠龍大劍、鳳凰弓、天雷 |
| 防具（9） | 皮帽、皮甲、木盾、鐵盔、鐵盾、輕靴、鎖子甲、荊棘盾、聖騎士盾 |
| 其他 | 錢袋（第 4 節）、地城裡的藥水（消耗品） |

- 沒有升階、沒有合成；飾品、寵物、職業核心道具都不做（核心改成出發前裝備，第 6 節）。

### 5.2 稀有度與詞綴（0.1.4 照 D2）

| 稀有度 | 顏色 | 詞綴 |
| --- | --- | --- |
| 普通 | 灰 | 0 條 |
| 魔法 | 藍 | 1～2 條（前綴、後綴各最多 1 條），名字是「前綴的底材」 |
| 稀有 | 黃 | 3～6 條（前綴、後綴各最多 3 條），有隨機名字（例：鴉之牙） |

- **T12～T1**（T1 最強），每條詞綴一個數值範圍切成 12 段，越高段越寬（`data.js` 的 `T12`）。第 1 層最好 T12～T11，越深越好（`dungeon.js` 的 `bestTier`：每深一級約 +1.25 階、熱度 Ⅱ 以上 +1 階、王 +2、生肖的黃裝最差 T3），第三座地城才看得到 T1、T2；擲到好的 T 機率越低。
- **詞綴不能重骰**（沒有鐵匠）：打到好詞才珍貴、才有交易價值。
- 前綴（數值）：傷害 %、物理、附加火焰／冰冷／閃電／混沌、生命、護甲、閃避、格擋。
- 後綴（機制）：攻速、暴擊、吸血、五種異常機率、相鄰／孤狼／據角／列陣、再生、荊棘、**四種抗性與全抗**。
- 掉落機率（`lootBag`）：小怪 藍 30%／黃 4%、寶箱 45%／10%、菁英 必藍、35% 黃、王 必有一件黃、生肖 必有一件黃；熱度越高越好。
- 舊存檔（0.1.3 以前，T6～T1）：T 乘 2，數值夾進新範圍。

### 5.2.1 屬性與抗性（0.1.4 照 PoE）

- 五種傷害：物理、火焰、冰冷、閃電、混沌。**護甲只擋物理**（每下扣護甲值）；元素與混沌照**抗性**減傷：抗性多少 % 就少吃多少 %，**上限 75%**，可以是負的。
- **越深越要抗性**：第二座地城起每座 -15%（最多 -60%，PoE 每過一幕扣抗性的概念）。整備畫面顯示的抗性已經扣掉選的地城。
- 武器屬性：火球法杖、火焰弓＝火；冰錐法杖＝冰；雷霆錘、天雷＝電；毒匕首＝混沌；其他物理。詞綴「附加 X 傷害」另外加。
- 怪物：鬼火、燈籠妖打火，雪原狼打冰，雷蝠打電，毒菇、百步蛇打混沌，牠們也抗自己的屬性；菁英詞綴烈焰／冰霜／雷暴讓牠打那個屬性、抗 40%；怪物背包裡的抗性詞綴也算。遭遇畫面標出攻擊屬性與抗性。
- 持續傷害：燃燒算火、中毒算混沌、流血不吃抗性。

### 5.3 異常狀態（第一版 5 種）

燃燒（每層每秒 1 傷害，每 2 秒少 1 層；武器觸發 +2 層）、中毒（每層每秒 1，慢慢退）、流血（每層每秒 2，每秒少 1 層）、凍結（下一擊延後 1 秒）、感電（每層受到傷害 +8%，最多 5 層）。規則從《塞令老師》的 `異常清單.md` 挑，機率觸發一律用偽隨機 `prd`。

## 6. 職業、核心、天賦

**A**：第一趟就玩得到職業的特色；每一趟都在解鎖新東西。
**D**：每個職業都有人玩、核心組合有分歧；職業會偏好某些武器，但不是只能拿那些。

### 6.1 職業（第一版 5 個）

一開始就能選。每個職業有一個**不看武器標籤**的主機制（設計原則第 7 節），一開始就有；武器只影響疊得快慢。

| 職業 | 主機制 | 偏好 |
| --- | --- | --- |
| 浪人 | **架勢**：每次攻擊 +1 層，滿 5 層下一擊是居合（傷害 ×3） | 攻速快的武器 |
| 騎士 | **盾勢**：護盾每吃掉 20 點傷害 +1 層（最多 20），每層傷害 +2% | 防具、盾多 |
| 火法師 | **燃燒**：所有命中都疊 2 層燃燒，核心負責引爆 | 打很多下的武器 |
| 刺客 | **印記**：命中 +1 層，滿 8 層下一擊消耗：必定暴擊、每層 +5% | 暴擊、攻速 |
| 馴獸師 | **獸群**：開戰帶一隻戰狼，每攻擊 6 次再召喚一隻（最多 3 隻），狼每 1.5 秒咬一下（你平均一擊的 40%） | 攻擊次數多 |

- 主機制與核心沿用《塞令老師》（`docs/職業與核心.md`、`docs/騎士與刺客重製.md`），**拿掉跟武器標籤綁在一起的部分**。
- 之後再開放其他職業（狂戰士、弓箭手、亞馬遜、冰法師、雷法師、毒師、鍊金術士）。

### 6.2 核心

- 每個職業一開始送 1 個最簡單的核心。
- **出發前裝 2 個核心**（從已解鎖的挑），不占背包格子；死了不會失去。
- 核心分角色：製造、收割、續航、控制，兩個不同角色的核心要能相乘。
- 0.1.0 每個職業 6 個核心（清單與數值在 `js/data.js` 的 `CLASSES`）；之後加到 8～12 個。

### 6.3 天賦樹

- 每個職業一棵小樹，19 個節點（7 排，`js/data.js` 的 `TREE`；第 r 排要先點滿 ⌊1.5r⌋ 點），三種節點：
  - **解鎖核心**：把一個新核心加進可裝備的清單。
  - **強化核心**：門檻變低、數值變高（例：架勢 5 層 → 4 層）。
  - **小數值**：生命、傷害等。
- **用那個職業出地城才拿那個職業的經驗**，撤離成功拿得多、死亡也拿（每一趟都有進度）。
- 在城鎮可以免費重點。
- 沒有昇華、沒有轉職。

## 7. 城鎮（0.1.3）

底部五個分頁（0.1.4）：

| 分頁 | 功能 |
| --- | --- |
| 出發 | 選地城、職業卡（點了到「職業」）、整備卡（背包、生命、每秒、護甲、四種抗性，點了到「整備」）；下地城 |
| 整備 | 選要背的背包、背包＋倉庫（分類篩選）＋黑盒，拖曳搬動；點道具可以賣給商店或上架市集 |
| 市集 | 真人交易（見 7.1） |
| 商店 | 「裝備」：上方切換「放進背包／放進倉庫」，商品（格子卡片：框色＝稀有度、★ 等級、右上形狀、價格）直接拖進去就買下來，點一下看說明再買；「背包」：買背包 |
| 職業 | 換職業、換 2 個核心、點天賦 |

- **拿掉鐵匠（0.1.3）**：詞綴不能重骰。D2 經典的原因之一就是裝備詞綴掉下來就定了，所以打到好詞的那一刻才是真的中獎，好裝備稀有，交易才有價值。
- 道具說明（0.1.3，照《塞令老師》）：點一下道具，說明卡從底部升起（不擋畫面，可以邊看邊拖），旋轉、放進背包／黑盒、賣出、上架的按鈕都在卡片上；地城裡背包說明卡開著時改從頂端降下來，不蓋住戰利品。
- 「背包夠強才能去更深」不做戰力門檻：**打倒那座地城的王才解鎖下一座**。
- 之後：裁縫師（背包縫特殊格）、增加愛心數的建築、更多地城。

### 7.1 市集（0.1.3，真人交易）

- **A**：打到好東西不只自己用，還能賣；缺的東西可以買。**D**：好詞綴的裝備有行情，玩家為了賣錢去刷高 T。
- 上架：倉庫裡的道具點「上架市集」、自己定價（1～99999 金，參考價是賣給商店的 3 倍）；同時最多 20 件；上架就從倉庫拿走，下架放回倉庫。
- 購買：用金幣買，買到的放進倉庫；同一件只會成交給一個人（`market_buy` 一次更新）。
- 領錢：賣掉的錢扣 **10% 手續費**（金幣回收），到「我的上架」領。
- 技術：Supabase 表 `dungeon_market` 與函式 `market_buy`／`market_cancel`／`market_claim`（`supabase/migrations/20261031000000_dungeon_market.sql`）。從市集來的道具會檢查底材、詞綴、T 級與數值範圍（`gear.js` 的 `cleanItem`），不對的不收。
- **已知風險**：金幣與道具存在玩家自己的存檔，伺服器不驗證道具是不是真的打到的（改存檔能變出合法數值範圍內的裝備）。人多了再補伺服器端的掉寶紀錄。

## 8. 經濟（草案）

- **金幣來源**：戰鬥、菁英、王、生肖、寶箱、事件。地城裡撿的金幣死了全部失去（放在黑盒錢袋裡的除外）。
- **金幣去處**：背包（主要的消耗，因為死了背包會失去）、商店白裝、地城商人、市集（10% 手續費是回收）。
- 目標：一趟撤離成功的收入，大約夠買一個同級的背包＋幾次重骰；死一次會痛，但跑刀幾趟就能回來。

### 9.0 新手教學與設定（0.1.1）

### 9.1 戰鬥畫面

- 資料夾 `dungeonPOE/` 自己就能跑（自己的 `index.html`、`css/`、`js/`、`img/`、`art/`、`docs/`、`tools/`、`CLAUDE.md`、`.claude/skills/`），以後可以整個搬到別的 repo。網址 `…/wayfarer/dungeonPOE/`。

- 從 git 歷史挖：原始 25 件道具（`f2041b1` 的 `js/items.js`）、詞綴表與台灣妖怪（`bfd1c43` 的 `js/data.js`、`js/foes.js`）、十二生肖（`docs/舊企劃書_漫步勇者.md`）。
- 新寫：地圖生成、手牌、熱度與生肖、撤離與死亡、詞綴、城鎮、職業與天賦、存檔。
- 存檔：localStorage 新的鍵；雲端用同一個 Supabase 專案的新表 `dungeon_saves`（結構同 `saves`，RLS 只允許本人讀寫）。沒有排行榜、沒有快照。
