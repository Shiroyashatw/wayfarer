# dungeonPOE

背著背包下地城：在隨機地圖上點格子走過去，背包裡的裝備就是你的戰鬥力（全自動戰鬥）。熱度越來越高，墮落十二生肖開始追殺你之前，帶著寶物撤離。死了全部失去，只有黑盒裡的東西保得住。

- 線上遊玩：https://shiroyashatw.github.io/wayfarer/dungeonPOE/
- 目前版本：v0.1.4（[更新紀錄](CHANGELOG.md)）
- 企劃書：[docs/企劃書.md](docs/企劃書.md)・設計原則：[docs/設計原則.md](docs/設計原則.md)
- 建議用手機直式開啟

## 內容（0.1.0）

- 5 個職業（浪人、騎士、火法師、刺客、馴獸師），主機制不綁武器；每個職業 6 個核心、19 個天賦節點，出發前裝 2 個核心
- 16 把武器、9 件防具，照 D2 分白、藍（1～2 條）、黃（3～6 條）；詞綴 T12～T1，不能重骰
- 照 PoE 的四種抗性（火、冰、電、混沌，上限 75%），越深的地城扣越多
- 16 種形狀的背包（新手 3×3、3×5、5×3、4×6、L 形、十字、環形…），死了背包一起失去；黑盒 3×3 永遠保住
- 怪物也有背包：裡面的裝備讓牠變強，打贏就是你的戰利品；開打前看危險等級
- 熱度與墮落十二生肖、台灣妖怪小怪／菁英／王（魔神仔、虎姑婆、林投姐…）、民俗事件、地城商人
- 城鎮：整備、倉庫、市集（玩家之間交易）、商店（裝備與背包）、職業與天賦；詞綴不能重骰

## 開發

純靜態網頁，不需要建置：在這個資料夾裡 `python3 -m http.server 8000`。檢查：`node tools/check.js`；平衡：`node tools/autoplay.js 30 --greedy`。開發規則見 [CLAUDE.md](CLAUDE.md)。
