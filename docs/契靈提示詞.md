# 契靈與召喚物提示詞（PixelLab）

先不跟怪物一起批次產，之後另外生成。共用設定、句型照 `docs/怪物提示詞.md`。批次產圖：
`python3 tools/pixellab_batch.py run docs/契靈提示詞.md --n 2`
接進遊戲後，把採用的提示詞記到 `docs/怪物提示詞.md` 的「已採用」。

## 契靈與召喚物（`js/gacha.js` 的 `PACTS`、`js/skills.js` 的召喚技能）
契靈和召喚物是**站在玩家這邊**的，結尾不用兇殘句型，改成 `loyal, determined expression`；一樣面向左（跟其他怪物共用同一套繪製）。一般怪物設定（64、Medium），SR 以上的契靈 Detail 改 Highly detailed。接入時改 `PACTS` 或召喚技能 `pet` 的 `spr`。
- 跟野怪同一隻的不另外畫，野怪圖做好後直接共用：草原史萊姆 `m_slime_green`、夜鷺 `m_nightheron`、招潮蟹 `m_fiddler`、巷口黑貓 `m_blackcat`、石虎 `m_leopardcat`、獨角仙 `m_beetle`、穿山甲 `m_pangolin`、樹蛙 `m_treefrog`、燈籠妖 `m_lantern`、台灣黑熊 `m_blackbear`、百步蛇 `m_hundredpace`、雲豹 `m_cloudleopard`、熊鷹 `m_hawkeagle`、綠蠵龜 `m_seaturtle`、風獅爺 `m_windlion`、水鬼 `shuigui`；召喚的骷髏用 `skeleton`、怨靈用 `wraith`。
- Init Image：鳥類拿 `z_rooster.png`、四足拿 `z_dog.png`、人形拿 `zhongkui.png`。
