# 圖示圖表（PixelLab 一次產 64 個）

這份是 `python3 tools/icon_sheets.py build` 從 `docs/圖示提示詞.md` 自動產生的，**不要手改**（要改提示詞改那份，再重跑 build）。

每張圖表 8×8 格、每格 32×32，整張 256×256，一次產 64 個圖示；同類系放同一張，風格才統一。

## 怎麼產

1. PixelLab → Create image（Pixflux）：Width／Height 照每張的尺寸、勾 **Transparent background**、Outline 選 **Black outline**、Detail **Medium**，把該張的提示詞整段貼上。畫布面積上限：免費方案 200×200、Tier 1 320×320、Tier 2 以上 400×400；**每張 64 格（256×256）要 Tier 1 以上**，免費方案用 `--per 32` 重產這份（256×128）。
2. **先產 `sheet_skill_1` 當風格基準**，滿意了再產其他張；其他張都把這張當 **Style／Init Image** 參考，整套才會一致。
3. 下載 PNG 放進 **`art/sheets/`**（檔名就是圖表名稱，例如 `sheet_skill_1.png`），跑 `python3 tools/icon_sheets.py process`：全部切成一格一張（照下面的對照表存到 `art/icons/`，實心背景自動去背）、打包進遊戲，再把做完的提示詞與圖表封存。跟 Claude 說「放了新圖」它會幫你跑。
   圖表編號固定不變：這裡列的都是還有格子沒圖的；做完的移到 `docs/提示詞封存.md`，原圖在 `art/sheets/done/`。
4. 格子歪掉或某幾格不好：那幾個用 `docs/圖示提示詞.md` 的單張提示詞補產。
5. 提示詞太長被截斷（後面幾格畫不出來）：`python3 tools/icon_sheets.py build --words 6` 縮短每格的描述，或 `--per 32` 改成每張 32 格。
