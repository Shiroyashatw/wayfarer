# 圖示提示詞（PixelLab）

裝備、技能、輔助寶石的圖示提示詞。怪物、首領的在 `docs/怪物提示詞.md`。

目前遊戲裡的圖示都是程式畫的：裝備是 `js/gear.js` 的 12×12（`GEAR`，材質階級換色由 `tierOf` 處理），技能是 `js/sprites.js`／`js/skills.js` 的 8×8（技能資料的 `icon`）。**PNG 圖示還沒有接入的工具**（`tools/art.py` 只處理怪物），生好之後要先做一個圖示版的轉檔（例如 `art/icons/` → `js/icons.js`），再讓 `gearIcon`、技能格改用 PNG。

## 共用設定

PixelLab → Create image → 模型 **Pixen**

| 項目 | 裝備圖示 | 技能圖示 | 輔助寶石 |
| --- | --- | --- | --- |
| Width | 32 | 32 | 32 |
| Transparent background | 勾選 | 勾選 | 勾選 |
| Direction | None | None | None |
| View | None | None | None |
| Detail | Low／Medium | Medium | Medium |
| Outline | Black outline | Black outline | Black outline |

- 圖示很小（遊戲裡顯示約 24～32px），**形狀要一眼看得懂**，不要加立體感那段、不要寫細節太多，會糊。
- 同一類先挑一張滿意的當 **Init Image**（例：武器先生長劍、技能先生火球術），其他都拿它當參考，整套才會一致。
- 不要文字（`no text`），也不要外框（框由遊戲畫）。

## 裝備圖示（底材 54 種，`js/data.js` 的 `BASES`）

**金屬一律畫灰色**（皮革畫棕、布畫灰），材質階級的換色交給程式（`js/gear.js` 每種底材都有材質：metal、leather、cloth、wood…）。檔名建議 `art/icons/gear_欄位_序號.png`（序號照 `BASES` 的順序，從 0 開始），例如長劍是 `gear_weapon_1.png`。
- 武器、副手：斜放（左下到右上）。
- 頭盔、胸甲、手套、鞋子：正面（front view）。
- 戒指、護身符：俯視斜角；寶石照名字的顏色畫（紅寶石紅、藍寶石藍）。
- 傳奇裝備之後要專屬圖示時，同一句型把 `plain grey iron` 改成該傳奇的材質與顏色（例：`black iron with glowing crimson cracks`）。
