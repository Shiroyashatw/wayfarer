# 圖示提示詞（PixelLab）

塞令老師的道具圖示提示詞（每張圖示一列）。舊版（漫步勇者）的提示詞在 `docs/提示詞封存.md`。

**建議用圖表一次產 64 個**：`python3 tools/icon_sheets.py build` 會從這份自動組出 `docs/圖示圖表.md`（同類系的放同一張 8×8 圖表、共用同一句風格，約 13 張就產完），產好用 `tools/icon_sheets.py slice` 切成一張張。這份的單張提示詞留著給補產或重產某幾張用（`py tools/pixellab_batch.py run docs/圖示提示詞.md --only sk_fire`）。新增技能、輔助寶石、節點時在這份補一列，再跑一次 build。怪物、首領的在 `docs/怪物提示詞.md`。

目前道具借用舊版的技能、輔助寶石 PNG 圖示（`js/items.js` 每件的 `ic`）；`art/icons/it_道具代號.png` 產好之後會優先用新的。

## 共用設定

PixelLab → Create image → 模型 **Pixen**

| 項目 | 裝備圖示 | 技能圖示 | 輔助寶石 |
| --- | --- | --- | --- |
| Width | 32 | 32 | 32 |
| Transparent background | 勾選 | 勾選 | 勾選 |
| Direction | None | None | None |
| View | None | None | None |
| Detail | Low／Medium | Medium | Medium |
| Outline | Black outline | Black outline | Black outline |

- 圖示很小（遊戲裡顯示約 24～32px），**形狀要一眼看得懂**，不要加立體感那段、不要寫細節太多，會糊。
- 同一類先挑一張滿意的當 **Init Image**（例：武器先生長劍、技能先生火球術），其他都拿它當參考，整套才會一致。
- 不要文字（`no text`），也不要外框（框由遊戲畫）。
