# 漫步勇者 企劃書（肉鴿版）

> 0.1.0 起改成**短局肉鴿**。舊的「GPS 走路練等」版本企劃在 `docs/archive/企劃書_走路版.md`（技能石、詞綴、天賦、昇華、怪物的細節設計大多沿用，可以去那裡查）。

## 1. 一句話

台灣妖怪題材的手機肉鴿：一局 15～20 分鐘，三章節點地圖一路往上打，每場勝利三選一，用 PoE 式的技能石、輔助寶石、詞綴裝備、天賦與昇華組出這一局的 Build。

## 2. 為什麼改

- 試玩反饋：普通、沒特色、地圖沒用。手機玩家不再花時間練等，需要「打一局就有結果」的短局。
- 原本的技能石、輔助寶石、詞綴製作、天賦、昇華都很適合變成局內構築的獎勵，怪物與首領的圖、機制也都能直接用。

## 3. 一局的流程

1. **主選單**：開始新局（選角）、每日挑戰、局外升級、契靈祈願、設定。
2. **選角**：8 個角色＝昇華的 8 個職業，各有起始武器與 2 顆起始技能石（另外都有治癒）。鬥神、元素使、道士一開始就能玩，其他用魂晶解鎖。
3. **三章**，每章一張 10 層的節點地圖（`run.js` 的 `genMap`）：從最下面 3～4 個起點往上，每層 2～4 個節點，路線不交叉；第 9 層是首領。

| 章 | 主題 | 怪物 | 菁英 | 首領 |
| --- | --- | --- | --- | --- |
| 第一章 | 山林 | 森林、草原、高山的野怪 | 墮落獸（暗紅墮落版圖） | 台灣鬼怪（魔神仔、虎姑婆、陳守娘、椅仔姑、林投姐、水鬼、冥婚新娘、紅衣小女孩、吊死鬼） |
| 第二章 | 城市・夜市 | 城市野怪、紙紮人、珍奶史萊姆、臭豆腐怪、八家將、海盜… | 七罪信徒 | 十二生肖、四凶、海盜王 |
| 第三章 | 冥府・魔霧 | 亡靈、魔霧怪、冥府小怪、山海經異獸 | 冥府看門人（牛頭、馬面、黑白無常） | 七宗罪之王、亡靈王、燭龍、閻羅王 |

4. **節點**

| 節點 | 內容 | 出現 |
| --- | --- | --- |
| 戰鬥 | 一隻帶頭（25% 魔法怪）＋小怪：第 0 層沒有、第 1～3 層 0～1 隻、第 4 層起 1～2 隻 | 第 0 層全部 |
| 菁英 | 稀有怪，詞綴數＝章數；第二章起多一隻小怪 | 第 3 層起 |
| 事件 | 台灣民俗事件（`events.js`），選項有代價、風險、祝福 | |
| 商店 | 藥水、通貨、裝備、技能石、輔助寶石；可以賣裝備 | |
| 休息 | 回 35% 生命＋魔力全滿，或技能欄的一顆技能石 +1 級 | 第 5 層起；第 8 層全部 |
| 寶箱 | 裝備與通貨；第二章起 20% 是寶箱怪 | 第 4 層全部 |
| 首領 | 章末首領 | 第 9 層 |

5. **戰鬥**：沿用原本的即時行動條戰鬥（行動條、冷卻、技能石、輔助寶石、戰場單位、怪物招式）。設定可以調戰鬥速度 ×1／×1.5／×2。
6. **勝利**：經驗與金幣照節點給；掉寶照怪物；然後**獎勵三選一**（技能石、輔助寶石、裝備、金幣；首領是 `bossPicks` 的首領寶箱）。每場勝利回 25% 生命、魔力全滿。
7. **升級**：每升一級**天賦三選一**（天賦樹的重要節點，名字不重複；每 10 級改成基石三選一）；組隊、地圖才有用的節點不出現。每升一級也自帶傷害 +5%、生命 +2%。
8. **首領之後**：昇華三選一。第一章首領選分支（這個職業的 3 條），第二章首領從分支的大點抽 3 個。每打倒一個首領多一個契靈欄位。
9. **結束**：死了或打通第三章，結算魂晶與祈願石，回主選單。設定裡可以放棄這一局（照進度結算）。

## 4. 數值

| 項目 | 規則 | 程式 |
| --- | --- | --- |
| 怪物等級 | 章的起點（1、12、23）＋每層 0.8；首領是第 8 層 +1 | `runLv` |
| 經驗 | 一般戰鬥 1.1 級、菁英 2 級、首領 2.5 級、非戰鬥節點 0.5 級（照目前等級的需求量換算） | `runGain`、`nodeDone` |
| 升級需求 | 20＋18×等級 | `xpNeed` |
| 金幣 | (15＋怪物等級×3)，菁英 ×2、首領 ×4，±15% | `runGain` |
| 掉寶加成 | 每章 +15% | `runLootQ` |
| 菁英 | 稀有（生命 ×2.4、攻擊 ×1.3）後再 生命 ×0.75、攻擊 ×0.85 | `eliteGroup` |
| 首領 | 保留各自機制與詞綴，生命＝70×(1＋0.38×(等級−1))×(2.2／2.8／3.4)，攻擊＝12×0.8×(1＋0.2×(等級−1))×(1／1.05／1.1) | `bossGroup` |
| 勝利回復 | 生命 25%、魔力全滿 | `RUN_REST` |
| 每級成長 | 物理、法術、元素傷害 +5%，生命 +2% | `RUN_LV`（`events.js`） |

平衡用加速代打測過（6～10 倍速、簡單出招策略）：一般戰鬥大多無傷到小傷，菁英與首領是主要的死因，偶爾能通關。之後依真人試玩再調。

## 7. 存檔

- localStorage 鍵 `wayfarer_rogue_v1`，格式標記 `fmt: 'rogue1'`；舊的走路版存檔不讀。雲端照樣存在 Supabase `saves`，讀到舊格式就當新玩家。
- 角色欄位（等級、裝備、技能石、天賦、昇華…）放在 `S` 最上層，開新局時 `newChar()` 蓋掉；局外的在 `S.meta`（魂晶、局數、解鎖、升級、每日）、`S.pact`、`S.cur.wish`；一局的進度在 `S.run`（種子、章、地圖、目前節點、已完成、擊倒數、祝福、重抽…）。
- `migrate()` 只用新遊戲的預設值補缺的欄位，之後加欄位不用寫版本轉換。
