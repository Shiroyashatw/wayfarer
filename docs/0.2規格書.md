# 0.2 規格書：職業分支與分支池

狀態：**暫緩，等數據**（2026-10-26）。骨架（分支、重做職業、縮小共用池）先不做；先量 0.1.99 的基準（第 5 節），數據證明撞職業真的吃虧再回來。0.1.x 先做**質變核心**（見下方「討論結論」）。0.2 是 0.1.x 之後的大改版，方向來自 0.1.99 的討論（`docs/設計原則.md` 的 MDA 與隨機性規則）。

## 討論結論（2026-10-26，取代第 3 節的部分草案）

為什麼暫緩：0.1.99 想湊的道具被收光只有 0.5%，共用池現在沒有卡人；草案是「先縮小池子製造問題，再用分支解決」。真正想要的新鮮感與自我表達（質變、更多核心）不需要改骨架就能做。

| 決定 | 內容 |
| --- | --- |
| 先做：質變核心（0.1.x） | 4-4 的三選一 = 2 個新核心＋1 個「你 2-5 那個核心的質變」。質變**取代**原本的核心（像 PoE 的質變技能）；可以強化原本的機制，也可以改成別的效果，兩種都做。強度要對齊「拿兩個核心」。先做一批招牌核心的質變上線，沒有質變的核心 4-4 維持三個新核心，再逐步補齊。 |
| 先做：量基準 | 第 5 節的 0.1.99 基準，結果寫在下面「基準」。 |
| 之後要做分支時照這版 | 每個職業 4 條分支、每條 3 個核心（照現有核心分；分不出來的職業要重做核心）。2-5：4 條抽 3 條、每條隨機出 1 個核心（**沒有固定入口**）。4-4：自己分支剩下的 2 個＋質變，不給別條分支的核心（給了就回到原點）。13 個職業全部一起上。 |
| 分支不能綁主題 | 分支只用每局都有的機制（異常、羈絆、擺位、出手、合成）；主題專屬效果只能當加分或放進質變。 |
| 盤點時融合新機制 | 七宗罪、塔羅、星河、異常、各主題擺位軸，用來做出分支之間的差異。 |

### 基準（0.1.99，機器人對局 480 場、2880 個機器人，分數 1300）

| 指標 | 結果 | 解讀 |
| --- | --- | --- |
| 撞職業的比例 | 51%（同一場有另一個同職業） | 很常撞 |
| 撞職業的名次差（扣掉職業本身強弱） | +0.05 名（1～6 名） | **幾乎沒有代價**；Ⅲ 階以上件數 1.10 vs 1.21（少 9%） |
| 撞的人 2-5 拿到同一個核心 | 19% | — |
| 背包相似度（最後背包道具種類的 Jaccard） | 同職業 0.17、不同職業 0.15 | 背包主要由商店決定，職業只讓背包像一點點 |
| 2-5 同一個核心 vs 不同核心的背包相似度 | 0.174 vs 0.169 | **核心幾乎不改變買法** |

結論：撞職業現在不痛，0.2 骨架沒有數據支持，維持暫緩。另一個發現更重要：**核心幾乎不影響玩家買什麼**（至少機器人是這樣，可能是 `botPower` 沒有照核心調整買法，真人資料樣本夠了要再對一次）。所以質變核心要設計成**會改變要買什麼、怎麼擺**（D），不能只改數值，不然一樣只是表面上不同。

重跑：`node tools/branch_base.js 480`（約 10 分鐘）。

不採用：每職業 5～6 條分支、每條 6～7 個分支池（約 580 個核心，條數多也做不到每條要買的東西不同）；4-4 給別條分支的核心；把隨機性改放到賽制（賽制本來就在選職業前隨機，而且全場共用，分不開兩個同職業的人）。

## 1. 為什麼要改（問題診斷）

照 `docs/設計原則.md` 第 5 節的順序找問題：

| 層 | 現況 | 問題 |
| --- | --- | --- |
| A 樂趣 | 職業原本想給「目標感、新鮮感、自我表達」 | 同一個職業每局打法差不多，新鮮感很快沒了 |
| D 玩家行為 | 開局選了職業，就決定這局抓哪種武器；同一場有兩個同職業時，兩人搶同一批道具 | 撞職業的人**沒地方轉**：轉了等於放棄職業 |
| M 機制 | 13 個職業裡 10 個綁死 1～2 種武器類型；核心 12 個，2-5、4-4 各三選一，選項從同一個職業的 12 個裡抽 | 共用池兩難：池子小 → 撞職業的人卡死；池子大 → 可以無限抓、池子形同虛設（0.1.99 量過：想湊的道具被收光只有 0.5%） |

**結論**：問題不在池子大小，而在「同一個職業只有一條路」。保留職業的認同感（「我就是想玩寵物流」），在職業底下長出**分支**，讓同職業的人走不同的路、要買不同的東西。

### 討論過、不採用的方向

| 方向 | 不採用的原因 |
| --- | --- |
| 職業格（商店固定 1 格出自己職業的道具） | 玩家只會買職業格，其他 4 格的誘因變很小 |
| 職業延後到 2-5 首領才決定 | 解決不了撞職業：2-5 之後一樣只有一條路 |
| 職業改綁玩法、不綁武器 | 概念會亂（弓箭手拿鎚子插箭）；元素法師、馴獸師本來就是武器即玩法 |
| 拿掉職業、只留核心 | 失去「我想玩寵物流」的認同感 |
| 機器人避開同職業 | 治標：6 人一場、13 個職業，真人快照一定會撞 |
| 縮小共用池（單獨做） | 量過：12／9／7／6／4 時被收光 32%，Ⅲ 階件數少一半，撞職業的人直接卡死 |

## 2. 目標（A → D → M）

- **A 樂趣**：自我表達（我是馴獸師，而且是召喚流）、探索（這局的分支延伸是什麼）、挑戰（讀場、避開別人的路）。
- **D 期望的玩家行為**：
  1. 2-5 選分支時，會看同場的人走哪條路（讀場）。
  2. 同一場的兩個同職業，大多走不同分支。
  3. 同一個玩家連玩同一個職業，每局的分支、延伸、背包不一樣。
  4. 撞到同一條分支時，感覺得到「有人在卡」，但不是整個職業被卡死。
- **M 機制**：職業 → 分支（2-5 入口）→ 分支池（4-4 延伸），共用池縮小。

## 3. 規格

### 3.1 結構：職業 → 分支 → 分支池

- 每個職業 **3 條分支**。
- 每條分支有：
  - **入口核心**：2-5 首領的三選一裡出現，選了就決定這局的分支。
  - **分支池**：4-4 的第二個核心從這裡抽，是**這條分支延伸的效果**。
- **第一版用現有的 12 個核心組成**：每條分支 4 個 = 1 個入口 + 3 個在分支池。太薄或太像的分支才補新的延伸核心；之後再慢慢擴充每個分支池（新核心只做分支池的延伸）。

### 3.2 2-5：選分支

- 三選一，**保證三條分支各出一個入口核心**。
- 核心說明上方寫分支名（例如「召喚流」），玩家一眼看出方向。
- 刷新規則：待定（見第 6 節）。

### 3.3 4-4：分支池

- 第二個核心**只從自己那條分支的分支池抽**，三選一。
- 分支池不夠 3 個時的補法：待定。

### 3.4 讀場

- 2-5 之後，對手列表（準備畫面的對手按鈕、對手背包）顯示他的**職業＋分支**。
- 快照要存分支（快照格式加欄位，`GVER` 要換）。

### 3.5 分支的驗收標準（寫進 `docs/設計原則.md`）

每條分支都要通過：

1. **變強來源不同**：三條分支各靠不同的東西變強（例：召喚出來的單位／單一高階道具／道具數量／別類道具）。
2. **要買的東西不同**：分支只差數值、要的道具一樣的，不算分支（分散不了供給，縮小共用池只會讓大家一起卡）。
3. **至少一條分支不太依賴商店裡的職業主力道具**（撞職業時一定有路走）。
4. **一句話講得完**：「召喚流：靠戰狼，不用買很多寵物」。

### 3.6 共用池

- 分支做完後再縮小。起點 **18／15／12／9／6**（0.1.99 量過：被收光 5.3%、Ⅲ 階件數從 1.04 掉到 0.53），之後照第 5 節的指標調。
- 保底（0.1.99）照舊，只從池子剩下的抽。

### 3.7 雙修賽制

- 雙修的 4-4 改成從**別的職業的入口核心**挑（跨職業開第二條分支），不用分支池。

### 3.8 機器人

- 2-5 選分支：看同場的人走哪條，避開一樣的（跟真人的讀場一樣）。
- 4-4 從分支池挑；`botPower` 評估分支效果；重新訓練（skill `bot-ai`）、重算職業表、重傳種子（skill `ghost-seed`）。

## 5. 要量的指標（上線前後都量，skill `stats`）

| 指標 | 對應的玩家行為 | 目標 |
| --- | --- | --- |
| 同一場兩個同職業時，走同一條分支的比例 | D2 | 明顯低於 1/3（隨機選的機率） |
| 同職業同分支 vs 不同分支的名次差、合成完成率 | D4 | 同分支比較吃虧，但不是卡死 |
| 每條分支的選擇率與平均名次 | 分支平衡 | 選擇率不低於 15%、名次差在 ±0.3 內 |
| 同一個職業不同局的背包相似度 | D3 | 比 0.1.99 低 |
| 想湊的道具被收光的比例（縮小池子後） | D4 | 先抓 5～10% |
| Ⅲ 階件數、首領勝率（PvE） | 挑戰 | 不低於 0.1.99 太多 |

0.1.99 的基準（要先量）：撞職業時的名次差、同職業的背包相似度、核心選擇有沒有改變購買。
