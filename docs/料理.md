# 料理（草案，還沒實作）

基本池重做：拿掉基本防具、抗異常、剋寵物、淨化，以及各主題池的 24 件通用融合，改成 **7 種食材兩兩合成 28 道料理**。設計討論的結論都在這份；確認後才寫程式。

## A → D → M

**A（要給的樂趣）**
- **探索**：發現「這兩個合起來會變什麼」。
- **自我表達**：照自己的構築和場上的對手，決定要煮哪道菜。
- **挑戰的公平感**：遇到異常流有辦法減輕，但不會把對方癱瘓。

**D（期望玩家怎麼玩）**
- 會先買一個食材放著，等另一個出現再合成（像 TFT 的裝備零件）。
- 看到場上有異常流，會優先煮薄荷、咖啡、檸檬的料理；場上沒有就不煮。
- 煮出來的料理有分歧，不會每個人都煮同一道。

**M（機制）**：下面各節。

**為什麼這樣改（現況的問題）**
- 基本池 27 件裡有 14 件反制道具，2★ 商店有 35～54% 被基本池佔掉（巨人國最多），稀釋主題道具。
- 單一用途的抗性道具（避雷針 1.3%、墨鏡 5.1%、止血帶 6.6% 購買率）沒有需求就永遠不會買；淨化之鈴又是萬用解（設計原則第 3 節第 7 條）。
- 24 件通用融合，購買率大多 1.5～8%、最後持有 ≤1.4%：效果是小數字、看不出強弱，玩家「能塞就塞」。
- 以上數字是機器人對局（2026-10-24，0.1.100 之前），真人還沒查。

## 規則

1. **7 種食材，每種一個特性**（看名字就猜得到），見下表。
2. **合成**：把一個食材拖到另一個食材上，馬上變成一道料理（沿用融合的拖曳）。兩個一樣的食材＝那個特性的加強版。
3. **料理＝兩個食材的特性加起來 ×1.25**；兩個一樣的也是 ×1.25（就是那個特性的 2.5 份）。
4. **單獨的食材也有效果**：特性的一半（不然湊不到配方時食材是廢物，不敢先買）。
5. **分類界線**：食材和料理**只加角色本身**（生命、減傷、攻速、回復、抗性、淨化），**不給也不吃相鄰加成**，自己的框色與標籤 `food`。
6. **強度**：效果都是百分比，所以**不升階**也不會前期太強、後期太弱；食材不能 3 件升階（唯一用途是合成），料理也不升階。
7. **同一道料理只算一份**；不同料理可以疊，但**同一類抗性加總最多 50%**、淨化最多 4 次（只削弱、不歸零）。
8. 食材、料理都是 1 格；合成後空出 1 格。
9. **藥水和料理分開**：藥水＝一次性觸發（生命低於某個值喝下），料理＝整場被動。煉金術士只吃藥水，規則不變。

## 7 種食材（一份的數值，暫定）

| 食材 | 特性 | 一份 | 單獨放著（半份） |
| --- | --- | --- | --- |
| 肉 | 生命 | 生命 +8% | +4% |
| 麵包 | 減傷 | 受到的命中傷害 -5% | -2.5% |
| 魚 | 攻速 | 攻速 +6% | +3% |
| 蜂蜜 | 回復 | 每秒回復生命上限的 0.5% | 0.25% |
| 薄荷 | 抗持續傷害 | 受到的燃燒、中毒、劇毒、流血、撕裂、腐蝕 -12% | -6% |
| 咖啡 | 抗限制行動 | 凍結、冰緩、暈眩、麻痺、混亂、虛弱、致盲、破甲、衰老的時間 -12% | -6% |
| 檸檬 | 淨化 | 每 5 秒清掉身上最嚴重的 1 種異常，共 1 次 | 1 次 |

- 檸檬不吃 ×1.25：單顆、混合料理裡都是 1 次，**檸檬＋檸檬＝3 次**（取代淨化之鈴，萬用但次數有限）。
- 抗異常照類別抗，比較通用，所以數值壓低（加強版約 30%）；「只抗燃燒」這種專門抗性不放在食材，之後看數據再放到主題道具上（設計原則第 3 節第 7 條）。

## 待決定

1. **食材在商店怎麼出現**：後期商店幾乎不出 1★（背包 6×7 時 1★ 只剩 5%），食材不能單純定成 1★。建議：食材不照星級抽，**每一格商店固定有一個機率是食材**（例如 20%），價格固定。
2. 食材價格（建議 2 金、賣 1 金）、料理賣價（兩個食材相加）、池子裡每種食材幾份（共用池，被別人買走會變少）。
3. 獵人徽章要不要留（它是剋寵物裡有人買的，但不是藥水）。
4. 保底要不要延伸到「差一個食材就能合成」（設計原則第 3 節第 3 條，不能破壞共用池）。
5. 七宗罪：食材、料理不屬於任何一宗罪（不影響羈絆）。
