# 塔羅牌與星象圖表（PixelLab，每張 64×64；0.1.84 起 32 張都產完了）

兩個賽制共用一套卡片風格，剛好兩張 4×4 圖表（32 張）：
- **塔羅牌陣**的 22 張大牌（0.1.74）：四選一的牌顯示 64×64、上方賽制標籤顯示小圖；**逆位由程式倒過來顯示，不用另外畫**。還沒有圖時照舊顯示牌的編號。
- **星象輪轉**的 10 個月（0.1.83）：每個階段的規則用的月亮卡，檔名 `astro_月的代號`（代號是 `js/data.js` 的 `ASTROS[].k`）。

## 怎麼產

1. PixelLab → Create image（Pixflux）：尺寸 **256×256**、勾 **Transparent background**（卡片本身有深藍底，透明只是卡片外面）、Outline **Black outline**、Shading **Basic shading**、Detail **Medium**，貼上提示詞。
2. 第一張滿意的存下來當 **Style／Init Image**，第二張圖表、補產的單張都拿它當參考，整套才會一致。
3. 下載 PNG 放進 **`art/sheets/`**（檔名就是圖表名：`sheet_tarot_1.png`、`sheet_tarot_2.png`），跟 Claude 說「塔羅牌圖表放好了」：`python3 tools/tarot_cut.py` 照下面的格序切成 `art/icons/tarot_牌.png`、`art/icons/astro_月.png`（64×64，不裁邊；**PixelLab 畫的金框會被拿掉**，外框統一由畫面畫，所以有沒有框都沒關係）、跑 `tools/art.py` 打包，原圖搬到 `art/sheets/done/`。
4. 某幾格不好：用最下面的單張提示詞補產（64×64），存成 `art/icons/檔名.png` 再跑 `python3 tools/art.py`。
