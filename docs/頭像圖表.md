# 頭像圖表（PixelLab 一次產 16 個）

給玩家在設定裡選的「老師」頭像：**一張 4×4 圖表、每格 64×64、整張 256×256**，一次產 16 位（男 4、女 12，走俊男美女路線）。同一張產出來，畫風、頭身比、描邊才會一致。

目前的頭像是舊版的角色圖（鍾馗、門神、無常…，`js/data.js` 的 `AVATARS`）；這批產好後加進同一個清單，玩家在「設定 → 頭像」選。

> **狀態**：`sheet_avatar_1` 第一版已經上線（0.1.17，原圖在 `art/sheets/done/sheet_avatar_1.png`，切好的在 `art/monsters/av_*.png`）。一張圖表一次產 16 個，每個角色分到的細節比單張產少，看起來比怪物圖粗糙；之後要提升品質，用最下面的**單張提示詞一張一張重產**（64×64，把這張圖表當 Style 參考），產好直接覆蓋 `art/monsters/av_檔名.png` 再跑 `python3 tools/art.py`。

## 怎麼產

1. PixelLab → Create image（Pixflux）：Width／Height **256×256**、勾 **Transparent background**、Outline 選 **Black outline**、Shading **Basic shading**、Detail **Medium**，把下面 `sheet_avatar_1` 的提示詞整段貼上。畫布 256×256 要 **Tier 1 以上**（免費方案上限 200×200，就用最下面的單張提示詞一張一張產，64×64）。
2. 滿意的那張存下來當風格基準；之後要補格子或產第二張圖表，都把它當 **Style／Init Image** 參考，整套才會一致。
3. 下載 PNG 放進 **`art/sheets/`**，檔名就是圖表名稱（`sheet_avatar_1.png`），跟 Claude 說「頭像圖表放好了」：照下面的對照表切成一格一張（64×64，存到 `art/monsters/檔名.png`）、打包進遊戲（`tools/art.py`）、加進 `AVATARS`，再把做完的提示詞與圖表封存（提示詞搬到 `docs/提示詞封存.md`、原圖搬到 `art/sheets/done/`）。
4. 格子歪掉或某幾格不好：那幾個用最下面的單張提示詞補產（64×64，把圖表當參考）。
5. 提示詞太長被截斷（後面幾格畫不出來）：把每格的描述縮短成「髮色＋髮型＋一件代表性服裝」。

規則：跟現有的角色圖一樣是**全身站姿**（從頭到腳都在格子裡、腳踩在格子底部），身體稍微側向右前方；頭身比約 4 頭身、頭稍微大一點，遊戲裡大約顯示 36～72px，**臉、髮型和服裝輪廓要一眼認得出來**，配件不要太細。服裝都要完整、端莊（遊戲給所有年齡玩），性感感靠髮型、表情、配色表現。

## 共用風格（每張的開頭都是這句）

```
pixel art character sprite sheet: a 4 by 4 grid of 16 separate full-body characters, each character 64x64 pixels in its own equal cell, full body standing pose from head to feet, feet near the bottom of the cell, body turned slightly to the right, about 4 heads tall with a slightly large head, all characters in one consistent anime-inspired style: attractive faces with big expressive eyes, clean 1px dark outline, flat colors with soft cel shading, light from top-left, fully transparent background behind every character (no background squares, no colored tiles, no ground shadows, nothing outside the character), no text, no numbers, no grid lines, no frames.
```

## 攻擊動畫：中國四大美女（PixelLab Create animated object，16 格）

新頭像系列，跟上面的頭像一樣是**全身、約 4 頭身、動漫風、服裝端莊**，但會動：每人拿一件代表性的武器揮動攻擊，給戰鬥畫面播放用（目前頭像都是正面佇立的靜態圖）。

**怎麼產**（PixelLab → Create animated object）：
1. Size **64×64**（跟現有頭像同尺寸）、Frames **16**、勾 **Transparent background**；有視角選項就選側面（Side view）、**面向右（East）**——戰鬥畫面我方在左、朝右攻擊。
2. **Description** 貼「角色描述」那格、**Animation action** 貼「動作」那格（兩格都是英文，整段貼上）。
3. 先產一位滿意的（建議貂蟬），其他三位把它當 **Style 參考**，四人的頭身比、描邊、上色才會一致。
4. 下載 16 格的橫條（1024×64）或 4×4 圖（256×256），檔名用下表的 `檔名`（例：`av_diaochan_atk.png`），放進 `art/sheets/` 跟 Claude 說「動畫放好了」：切格、打包、接到頭像與戰鬥畫面。順便產一張**同角色的靜止站姿**（第 1 格也可以）當設定裡選頭像的圖。

**動作的節奏**（四位都照這個，播放才整齊）：第 1～3 格預備站姿（輕微呼吸）→ 4～7 格蓄力（武器往後拉、身體後仰）→ 8～11 格揮出（最快、加特效）→ 12～16 格收招回到站姿（第 16 格要跟第 1 格接得起來，可以循環）。
