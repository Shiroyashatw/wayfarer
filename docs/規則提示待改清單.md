# 規則提示待改清單（0.1.94 盤點）

起因：朋友試玩回饋：
- 「為什麼商店不能刷新？」（其實是抽到狂風市集）
- 棋盤王國「完全看不懂棋子要怎麼配合」，加成效果、連線都不明顯
- 結論：只會玩基本玩法，抽到的賽制和主題不知道怎麼玩

**病根**：規則寫在說明文字裡（開場介紹、規則按鈕、百科），但玩家是在背包和商店上做決定。
**原則**：規則出現在它生效的地方；看得到「會發生什麼」（擺之前）和「發生了」（觸發時）。

## 現況（程式裡已經有的）

| 已有 | 位置 | 問題 |
| --- | --- | --- |
| 開場介紹：轉盤＋規則條列 | `ui.js` 開場對話框（`mrules`） | 一次 3～4 條文字，看完就忘；之後要自己找規則按鈕 |
| 規則按鈕（賽制、道具池、塔羅） | `A.modeInfo`、規則對話框 | 要知道去點；狂風、七十二變等沒有常駐標記 |
| 點道具才亮起被它加成的道具（`lit`／`src`） | `bagHTML` | 要先點；只亮已經擺好的道具，**空格不提示** |
| 相鄰加成的金線 | `linkHTML` | 只畫「相鄰而且碰到」的（`adj`、`tf`）；**棋子這種遠距離的完全沒有線** |
| 被加成的道具右上角「＋」 | `bagHTML` 的 `buf` | 看不出是誰給的、加了多少 |
| 刷新鈕「不能刷新・買一件就換新」 | `ui.js` 商店按鈕 | 小字，沒有說是狂風；買了東西整排換新時也沒有提示 |
| 羈絆列、印記列、遺物列 | `SYN` 列、`MODEUI.sigil.bar`、`relic.bar` | 有，算是做得最好的部分 |
| 戰鬥時出手的道具會亮一下 | 戰鬥播放 | 齒輪充能、連鎖帶動、每第 N 次多打等**沒有任何事件**（`sim.js` 只改計時器），看不到 |

## 共用的新元件（先做這些，各賽制、主題再套用）

1. **規則標籤**：準備畫面上方常駐「圖示＋賽制名＋主題名」，點了看一句話規則。
2. **一句話規則**：每個賽制、主題補一個 `s`（一句話，15～25 字）給標籤、開場、提示用；`d` 留給詳細說明。
3. **觸發提示（toast＋小動畫）**：規則真的生效的那一刻跳一次，例如「狂風！商店換新」。同一種提示每局前 2 次才跳，之後只有小動畫。
4. **背包範圍提示**：選中或拖曳道具時，標出它影響的**格子**（含空格），不是只亮已經擺好的道具。棋子、凹口、遺物的位置規則都用這個。
5. **遠距連線**：`linkHTML` 支援不相鄰的加成（從來源中心畫到目標中心，虛線）。
6. **加成數字角標**：「＋」改成可以顯示數字或層數（例如森林相鄰 ×3、棋子 ×2）。
7. **戰鬥連動事件**：`sim.js` 對齒輪、連鎖、每第 N 次、棋子加成出手補事件，戰鬥播放畫線或閃光。
8. **第一次遇到的教學卡**：某賽制或主題第一次出現時，開局後跳一張圖解卡（不是條列），之後不再跳（記在存檔）。

## 建議順序

1. **共用元件 1～3**（規則標籤、一句話規則、觸發提示）＋**狂風市集**：每一局都受益，也是回饋裡最直接的問題。
2. **共用元件 4～6**（範圍提示、遠距連線、數字角標）＋**棋盤王國**、**共生森林**：同一套元件解決兩個主題。
3. **共用元件 7**（戰鬥連動事件）＋**機關城**：要動 `sim.js`，跑 `node tools/check.js --golden` 確認戰鬥結果不變。
4. **巨人國凹口**、**法老王遺物區域**、**黃道染色**：用前面做好的範圍提示和角標。
5. **教學卡（共用元件 8）**、其他★～★★的賽制。
6. 最後再看要不要調整解鎖節奏（目前約 60 場全開、解鎖後要自己去設定打開）。

每一步改完：用 `ui-design` 在手機尺寸截圖前後對照、跑 audit；有改說明文字跑 `item-text` 的 audit；動到 `sim.js` 跑 `check.js --golden`。
