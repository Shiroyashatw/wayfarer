# 質變核心（初稿）

狀態：**0.1.101 上線**（數值是第一版，實作時照 `tools/core_var.js` 調過；以 `js/items.js` 的 `CORE_VAR` 為準）。來源：`docs/0.2規格書.md` 的「討論結論」與基準（核心幾乎不改變買法）。

## 規則

- 4-4 首領的三選一：你 2-5 拿的核心有覺醒、質變的話，選項是 **1 個新核心＋覺醒＋質變**（加新的、做到極致、變一種）；沒有的話照舊三個新核心。
- 覺醒、質變都**取代**原本的核心，選了就沒有第二個核心，所以強度都要對齊「1＋1」（原本＋新核心）。第一版偏強，再用模擬（同一個背包換三種選項比勝率）和上線後的選擇率往下調：三個選項各不低於約 25%、名次差在 ±0.3 內。
- **覺醒**：原本的效果**全部保留**，再往同一個方向加強。
- **質變**：原本的機制**換掉**，只留主題，最多保留一個代表性的元素（像 PoE 的質變技能，不是多疊一個效果；疊效果就跟拿第二個核心一樣）。
- 驗收：每一個都要寫得出**改變的玩家行為**（改買什麼、怎麼擺）。只改數值的不算。
- 雙修賽制不出覺醒、質變；機器人要會選（`botPower` 要算到，重新訓練）；第一批沿用原本核心的圖示加標記。

## 已定案

- 4-4 用「1 個新核心＋覺醒＋質變」。
- 名單照重跑的核心統計（毒師用毒刺皮膚）。
- 覺醒保留原效果再加強；質變換掉機制、只留主題。
- 強度對齊「1＋1」，第一版偏強再往下調。
