# 技能特效提示詞（PixelLab VFX）

要用 PixelLab 的特效動畫換掉不適合的 pixelfx 特效。每一筆的 id 就是遊戲裡 `fxs(名字)` 的名字，換的時候不用改技能程式，只要換掉圖和 `js/fxsheets.js` 裡的那一列。

**先試這幾張**：盾牌粉碎、混沌箭、冰霜彈、火球。它們現在沒有專屬特效，或是畫成圓點、方塊，差別最明顯。

## 共用設定

| 項目 | 設定 |
| --- | --- |
| 背景 | 透明（Remove background） |
| 視角 | Low top-down（跟主角一樣，斜上方俯視） |
| 方向 | **有方向的特效（斬擊、投射物、衝撞）一律朝右畫**，遊戲會照出手方向旋轉 |
| 中心 | 爆炸、命中特效畫在畫布正中間；地面特效貼底部三分之一（看起來是在地上） |
| 輪廓 | 不要黑色外框（特效疊在怪物上，外框會很髒） |
| 尺寸 | 投射物、命中、近戰 64（使用者 2026-11-06 測過 32 太小）；範圍、爆炸 128 |
| 幀數 | 一次播完的 8～12 幀；循環的 6～8 幀，最後一幀要能接回第一幀 |

每一筆提示詞的開頭都加上這句：

```
pixel art VFX animation, transparent background, no character, no text, no frame, crisp pixels, dark fantasy action RPG, low top-down view, gritty and heavy, bold readable silhouette that fills most of the canvas, high contrast against a dark stone floor, rich shading with several tones per color, fast punchy timing around 20 frames per second,
```

遊戲裡的屬性顏色（提示詞裡寫的色碼就是這些）：物理 `#fff3e0`、火 `#ff8a4c`、冰 `#8fd6ff`、電 `#ffe066`、混沌 `#c38bff`、流血 `#d9304a`。

產出的圖放進 `art/fx/新名字/`（一幀一張 PNG，或一張橫排的序列圖都可以），跟我說一聲，我來切圖、接進遊戲。

---

**VFX 端點的強項（2026-11-06 實測）**：能量、火焰、衝擊波、爆炸很好；要畫具體物件（花、箭矢造型）或有細尾巴時容易失敗，例如混沌箭的細尾巴會像精子、花朵會變成一團線條。提示詞要寫清楚 `no tail`，也要求每幀形狀明顯變化。
