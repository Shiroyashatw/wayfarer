# 開場動畫的背景提示詞（PixelLab）

`js/intro.js` 的四張背景現在是程式畫的剪影。圖生好放進 `img/`，把路徑填進 `INTRO_ART` 就換成圖，分鏡與特效都不用動（圖會等比放大蓋滿畫面，手機直立只看到中間一段）。分鏡與字幕在 `docs/世界觀.md` 第 2 節。

**怎麼生**：Pixen，寬 320、高 180，**Side (Sidescroller)**，Detail: Highly detailed，No outline，不要透明背景。

**構圖**：主角放在畫面正中間的三分之一（手機直立只看得到那一段），地平線約在高度 58%，下面三分之一留給字幕，不要放重要的東西。不要字、不要 UI、不要人物特寫。

**十二神不畫進背景**：動畫一律用程式畫的發光剪影，墮落圖不能出現。
