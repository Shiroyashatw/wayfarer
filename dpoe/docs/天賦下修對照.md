# 天賦下修對照（0.2.7，已寫進 `PT_THEME`）

依據 `docs/PoE天賦參考.md`，這是 PoE2 0.5 版天賦樹的實際統計。樹的形狀不變，只改每個點的數值。等級上限改成 300，Lv100 共 119 點。

## 原本為什麼膨脹（更正）

- **大點的密度不是問題**：我們有 20% 是大點，PoE2 是 22%。
- **單點的數值太大**：例如生命小點給 +4%，PoE2 的 3074 個小點裡只有 1 個給 1% 生命；暴擊率給的是直接加的百分點。
- **計算方式錯了**：元素 % 另外相乘、等級另外給傷害（企劃書 7.2 會改掉）。
- **有直接減傷**：`lowHpRed`、直接加 % 的格擋。

## 規則

- **一個點只給一種東西**，不混搭。大點可以是「主效果＋條件」或「主效果＋代價」。
- **基礎能力點**：取代 PoE2 的「+5 屬性」點，約佔小點的 10%，放在主題和主題的交界處。一個點只給一種：生命 +10、魔力 +10、護甲 +20、閃避 +20、能量護盾 +8。
- **生命不給 %**：生命主要靠裝備和基礎能力點，大點最多給 3%。
- **沒有「更多」**：只有基石才有。
- **沒有直接減傷**。

## 實際寫進去的數值（跟上面的 PoE2 表不同的地方）

照 PoE2 的數字模擬，全押傷害的路線在 Lv90 還是有 +1300%（法術＋元素），因為我們的主題緊鄰、相鄰的主題會混搭，幾乎沒有過路點。所以小點再往下壓：

- 傷害類小點 +3%（PoE2 是 8～12%），攻擊速度小點 +1%，暴擊傷害加成小點 +4%，暴擊率提高小點 +6%，護甲／閃避／能量護盾小點 +8%，範圍 +3%，格擋機率提高 +4%。
- 手寫大點的傷害、暴擊數值減半；自動產生的大點＝小點 × 2.5 × 深度（強力大點 ×1.6 並附代價）。
- 生命主題的小點改成「每秒回復 2 生命」和「最大生命 +10」（PoE2 的生命回復速度 %，我們沒有這個數值）。
