# dungeonPOE 世界觀

2026-11-06 定案。故事圍繞一個問題：**神為什麼不再庇護我們？** 每個機制揭開一層，真相一層比一層糟。文字要淺顯：不用時辰、不用艱深詞。

## 1. 設定的鬆緊

| 分類 | 內容 |
| --- | --- |
| **鎖定** | 十二生肖神守護大陸；天裂之夜，天空被血紅裂縫劈開；十二神同夜墜落，砸出十二道裂口，地層就是這樣露出來的；之後墮落，血霧來自牠們的血；大陸生靈塗炭；遠征軍走進裂口後全滅；三年後，你在屍堆裡醒來；你死過一次，身上有神血 |
| **留白** | 誰劈開天空、裂縫另一邊是什麼、你生前是誰、你是不是遠征軍的一員、殺神的後果 |
| **預定方向（可改）** | 第 3 節的表 |

**新機制擴充規則**：只要回答它從哪裡來，不用改開場。

- **裂縫外**：七宗罪這類外來勢力。
- **地層下**：亡靈軍團、冥府。
- **人間**：人心、邪教、獵人組織。當年站出來對抗妖魔的人，三年後成了軍閥與世族，各自割據（不寫死）。

## 3. 各章的預定方向（可改）

| 章節 | 玩家以為 | 真相 |
| --- | --- | --- |
| 狩獵之血 | 生肖神背叛了人類 | 血霧是神流的血。牠們在流血，血霧循著你身上的神血追來 |
| 七宗罪 | 外來魔王打傷了神 | 七宗罪靠人心的罪滋長，弄髒了獻給神的供奉。傷神的是人自己 |
| 亡靈軍團 | 打倒墮落神就能救世 | 十二神鎮守的是大陸底下的冥門。神倒下一隻，門就開一道，而動手的是你 |
| 冥府 | 冥府是最後的敵人 | 地層就是冥府的上層。你本來已經死了，是十二神用最後的血把你送回來 |

現有機制的理由：

- **死亡**：你本來就是死者，所以死了還會回來。
- **狩獵進度條**：血霧跟著你身上的神血聚集，所以刷圖會累積。
- **5★ 變多**：血霧讓怪物更兇殘。
- **藏身處的十二神像**：打倒一隻生肖王就點亮一尊。玩家以為在拯救世界，其實每點亮一尊就開了一道冥門。

⚠️ 閻羅、牛頭、馬面現在是地圖王，等做冥府章再調整。
