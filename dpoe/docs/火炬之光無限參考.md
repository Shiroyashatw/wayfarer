# 《火炬之光：無限》（Torchlight: Infinite）手機打寶參考

> 2026-11-07 研究用，給「裝備價值重做」討論。研究環境只有搜尋摘要（maxroll、taptap、steamcommunity 抓不到全文），多數指南寫於 2023～2024（SS2～SS6），SS11～SS13 只有新聞稿等級；數字以當季遊戲內為準。

## 1. 裝備結構

| 項目 | 做法 |
| --- | --- |
| 稀有度與條數 | 魔法（藍）1～2、稀有（紫）3～5、無價（粉）6；一件最多 6 條 |
| 前後綴分組 | 前綴 3（基礎／進階／終極）＋後綴 3（同樣三級），每格一個池；SS6 後最強的詞幾乎都是終極級、只在無價裝上 |
| 階層方向 | **T0 最高**（數字越小越好）；一般掉落最高 T1，**T0 只能靠升階做出來**，且只有 ilvl 100 的基底能到 T0 |
| 固定詞 | 基底自帶基底詞；侵蝕可換成只有侵蝕才有的 Aember 基底詞（最多 4 條） |
| 品質、孔 | **沒有**（只有「能量」欄） |
| 可塑性 | 每件裝備的製作次數上限，原型打造每次扣，0 就不能再做；定向加工會把它用光（＝不可逆的分界） |
| 傳奇 | 出廠帶固定詞；SS6 刪掉傳奇製作與原型打造；SS11 嫁接把傳奇詞移到基底上 |
| 手機顯示 | 主說明框只列數值，點「詳細」才看每條的 T；遊戲內有「詞綴清單」查這件基底能滾什麼 |

## 2. 掉落與拾取

| 項目 | 做法 |
| --- | --- |
| 掉率目標 | 開發日誌：每件傳奇都要「relentlessly rewarding」；EA 掉太多，後調到「每小時約 1 件傳奇」，再回報約 3 件 |
| 過濾器 | 官方三套模板（初級／中級／高級），規則由上往下、第一個命中決定外觀；條件：類型、**詞綴（選多條，「至少幾條命中」＋「階層總和 ≥ X」）**、詞綴數、關卡等級、物品等級、能量；建議從寬的模板往下改，「隱藏比找回容易」 |
| 自動撿（契靈） | 免費版撿小餘燼、普通碎片、烈焰塵、燈塔；**付費通行證才撿大餘燼、烈焰砂**（P2W 討論裡被點名最多） |
| 手機痛點 | 玩家原話：「榨滿的 8-4 圖打完約 1 分鐘，然後花 3～5 分鐘走回去一個一個點地上的東西」 |
| 一眼認得出 | 稀有度顏色、過濾器規則決定外觀、「階層總和」條件：價值判斷交給規則，不是玩家掃說明框 |

## 3. 做裝

| 項目 | 做法 |
| --- | --- |
| 材料 | 烈焰塵（0～1 詞）→ 烈焰砂（2～4 詞）→ 烈焰元素（5～6 詞，也是交易貨幣） |
| 原型打造 | 鎖最多 2 條、其餘重擲，鎖越多越貴（要加對應詞的餘燼）；扣可塑性；低等級專案便宜到「鎖 1 條反覆重擲到滿意」。玩家評語「不用 PoE 代數學位」 |
| 定向加工 | 選詞綴群，結果在群內隨機；把剩餘可塑性用光，之後不能再原型打造 |
| 升階到 T0 | 用終極餘燼升一條；**會隨機移除另一條詞綴、沒有保底** → 玩家「湊一堆 T1 然後祈禱」 |
| 侵蝕 | 突變 25%／混沌 25%／傲慢（升 1 條，最高 T0+）30%／虛空 20% |
| 附魔 | 類 PoE 工藝台，每件一條 |
| 保底 | 做裝沒有保底，只有契靈抽卡 30 抽保底 |

## 4. 一局的節奏與操作

- 一張圖約 1 分鐘（撿東西 3～5 分鐘）；評論「核心循環短、暴力、快節奏」。
- 沒有自動尋路；SS4 起「靜止」媒介＝自動施放攻擊／法術；2026 有半掛機攻略。
- 手機：左搖桿、右邊技能鍵；**輕點＝自動瞄準、長按＝右搖桿手動瞄準**。桌機鍵鼠完整，PC 有長按拾取、手機沒有。PC 評論「鍵鼠沒問題，但明顯感覺是手遊」「選單多到瘋」。

## 5. 經濟與商業模式

- 交易所：便宜的用砂、貴的用烈焰元素；賣出課稅；免費 9 格、通行證 12 格（封測時砍到 1 格炎上）。
- 付費：契靈抽卡（加屬性與自動拾取等級，30 抽保底）、賽季通行證（新英雄特性、攤位格、進階自動拾取）、英雄特性直售。
- P2W 脈絡：封測承諾「只賣外觀」→ 跳票 → 評價轉為「比暗黑永生不朽好，但錢能買優勢」；Steam 褒貶不一約 69%；簡中長評「從有創造力的 ARPG 變成賽季制數值碾壓」。

## 6. 賽季

- 約 3 個月一季；每季＝**新觸發物（立方、塔羅、雕像、提燈）＋專屬通貨／掉落＋新英雄**；SS12 Lunaria 的連鎖觸發刷怪把 Steam 在線拉到歷史高峰（約 2.7 萬）。
- 季末：英雄、特性、契靈永久帶走；上季機制常轉常駐（SS12 在 SS13 轉常駐並降負擔）；抱怨「舊內容太快移除」「SS6 後進度變慢、掉落變少」。

## 7. 評價摘要

**爽**：「畫面被傷害數字炸滿但仍在掌控中」「循環短、暴力、快」「做裝不用代數學位」「很快升級、拿裝、清圖」。
**不爽**：契靈抽卡「掠奪式變現」、「重複的苦工」「選單多到瘋」、深度不如 PoE、「打 1 分鐘撿 5 分鐘」、「賽季制數值碾壓」。

## 手機市場值得學的 10 條

1. 一張圖 1 分鐘上下、循環「短、暴力、快」，別為了內容量把圖拉長。
2. 過濾器用「至少 N 條指定詞綴」＋「階層總和 ≥ X」，規則由上往下、第一個命中決定外觀：把「值不值得撿」交給規則。
3. 出廠三套模板，從寬的往下改，「隱藏比找回容易」。
4. 掉落封頂與製作終點分開（掉落最高 T1、T0 只能做），打寶與做裝各有上限。
5. 前後綴各三格、每格一個池：6 條裝切成 6 個可讀的格子，說明框一眼看「哪格還缺」。
6. 「鎖 1～2 條重擲其餘」當便宜的入門製作，鎖越多越貴。
7. 可塑性＝一件裝的製作次數上限，定向加工把它吃光：停損點與可逆／不可逆的分界一看就懂。
8. 輕點＝自動瞄準、長按＝手動瞄準；一套技能邏輯兩種輸入，不做手機簡化版。
9. 掉率先定「每小時幾件大獎」再調。
10. 每季＝新觸發物＋專屬通貨，季末轉常駐而不是移除。

## 要避開的 5 條

1. 自動撿分免費／付費兩階：既是 P2W 的箭靶，又直接製造「打 1 分鐘撿 5 分鐘」。
2. 影響掉寶或數值的抽卡。
3. 升階會隨機炸掉另一條詞綴且沒有保底：賭場不是製作。
4. 系統疊到「選單多到瘋」（原型→定向→侵蝕→嫁接→創造引擎→附魔）：一次只給一條清楚的做裝路徑。
5. 用調低掉落、拉長進度抬高付費道具價值，並隨季砍舊內容。
