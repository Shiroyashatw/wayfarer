# 寶石品質效果表（0.2.29）

> 狀態：**0.2.29 已實作。** 文字以 `js/data.js` 的 `QUAL` 為準，改了要同步。

## 讀法與原則

- 共 92 條：主動 57、輔助 27（現有 26＋自動化）、光環 8。
- 品質 0～20%。表上**所有數字都是品質 20% 的值**，低品質照比例線性算（品質 10% 就是一半）。
- 標 **〔階〕** 的是不能切一半的效果，品質每 5% 一階，共 4 階。
- 等級繼續給傷害，品質負責改玩法。原則是「讓玩家換一種打法」，不寫單純加傷害、加範圍。
- 流血、中毒的品質是加強異常強度（使用者指定）；其他退回數值的有 4 條，保留（見最後的已定案）。

## 底層新增的概念（0.2.29）

每項只寫一次，技能只呼叫它。

| 概念 | 用到的條目 | 放哪裡 |
| --- | --- | --- |
| 傳染：死亡或觸發時把狀態傳給附近的怪 | 時空鎖鏈、絕望、獵犬印記、混沌箭 | `combat.js` |
| 異常擴散：範圍上冰緩 | 冰凍印記、易碎 | `combat.js` |
| 分裂：投射物或地雷多生一個 | 穿透、爆裂地雷 | `skills.js`／`mech.js` |
| 拉怪：把怪移向一點 | 跳砸、旋風斬 | `combat.js` |
| 擊退到牆邊沉重暈眩 | 重擊輔助 | `skills.js` 的 `hitMob` |
| 魔像替你擋下一下（不改怪物 AI） | 召喚魔像 | `game.js` 的 `hurtPlayer` |

## 已定案（2026-11-04）

1. **精粉用量：** 技能、光環每 1% 花 1 精粉，輔助每次 +2% 花 1 精粉。
2. **帶數值的 4 條保留：** 狂暴、凋零、盾牌投擲、脆弱。
3. **流血、中毒：** 品質加強異常強度；劇毒、焦灼、易碎、殘喘維持機制效果。
4. **點燃擴散不放進品質：** 由昇華的「焚城」負責。

## 上線後要驗

不消耗類（撕裂、灌注新星、屍爆、雷鳴擊）和不進冷卻類（影襲）容易連鎖，要用 `tools/dmg_check.js` 和實際刷圖確認。
