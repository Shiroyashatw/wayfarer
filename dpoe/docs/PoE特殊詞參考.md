## 1. PoE1 追憶（Synthesised）固定詞

| 項目 | 內容 |
| --- | --- |
| 產生（3.6） | 3 件同部位、稀有或傳奇的破裂物放進合成器，產出 1 件追憶基底 ✅ |
| 固定詞怎麼決定 | 由三件身上所有詞綴決定；每條詞歸到一個群，加總過門檻 → 不同固定詞、不同階 ✅ |
| 一件幾條 | 1～3 條（條數＝隨機挑一件、看它幾條破裂詞）✅ |
| 覆蓋 | 取代基底原本的固定詞；之後腐化可換成腐化固定詞；食魔／滅燼會移除它 ✅ |
| 未鑑定看得到嗎 | 看得到：固定詞在分隔線上方，不受鑑定影響 ◐ |
| 現在怎麼拿 | 3.11 起合成器移除；只從追憶記憶圖／Cortex、劫盜、祭祀掉，不能自製 ✅ |

玩家最重視的（部位、數值）：所有技能寶石等級 +1（項鍊）、〈屬性〉技能等級 +1（項鍊、戒指）、插槽光環寶石 +1（頭盔）、插槽寶石品質 +4～6%（頭盔）、插槽寶石 +1（胸甲、武器）、所有最大抗性 +1%（盾、頭、胸）、額外詛咒 +1（戒指、項鍊）、額外投射物／額外箭（弓、箭袋）、擊殺獲得猛攻（鞋）、圖騰／魔像上限 +1（盾、首飾）、「若已腐化」限定詞（鞋移速 +5～7%、胸受傷 −5%）。

社群評價：追憶是「掉落限定、純正面、改規則」的代表；但價值集中在少數幾條（+1 技能、+1 詛咒、額外投射物），來源太稀，2024 年仍有人要求重做。

## 2. PoE1 瓦爾寶珠腐化

結果（社群共識各結果約等權重，GGG 未公布）：無變化（只多「已汙染」）／一條固定詞換成腐化固定詞／重骰成 6 詞稀有（插槽連結全隨機，傳奇變稀有＝最常見的炸掉）／插槽變白。雙重腐化（腐化密室）一次套兩個結果。3.3 起腐化固定詞約 176 條。

代表性腐化固定詞：插槽寶石 +1（胸、手、鞋、盾）、插槽光環／詛咒寶石 +2（盾、頭）、額外詛咒（項鍊、胸）、攻速 +8～10%（項鍊）、最大狂怒／耐力／暴擊球 +1（項鍊、手、鞋）、擊中詛咒（手套）、弓額外箭（弓）、穿透 8～10% 元素抗（法杖、細劍）、近戰擊中護體（單手劍）、直接給關鍵天賦「堅決技巧」（單手劍）、插槽寶石被 Lv10～15 輔助（武器）、免疫腐化之血／不被致殘（珠寶）、最大抗 +1%（頭）。

## 3. PoE2 瓦爾寶珠（0.1 → 0.3）

- 裝備結果：無變化／重骰（0.2 起＝套 1～3 次混沌寶珠）／加 1 個插槽（可超上限）／加腐化固定詞，各約 25%（玩家 100 次實測 29／28／22／21%）✅。0.3 結果表沒變，只改掉落（主要從混沌試煉）。
- 傳奇：無變化／腐化附魔／加插槽／把詞綴數值推到超過正常範圍，各 25% ✅。
- 寶石：25% 無變化、12.5% +1 等級、12.5% ±插槽、品質 ± ✅。
- 腐化預兆（Omen of Corruption）：移除「無變化」，其餘等比放大 ✅。這是最被接受的「保底」。
- PoE2 有腐化固定詞：分部位池，例頭盔「最大火抗 +1～3%」「召喚物技能 +1」、通用「+30～40 生命」✅。
- 「升一條詞的階／降階／變白／品質變化」這組裝備結果在 0.1～0.3 查不到，最接近的是 0.2.0 的 bug 修正與寶石的 ±等級。

## 4. 災魘聯盟（Scourge，3.16）

- 血之試煉：裝備放進去、在災魘界殺怪吸腐化、轉化 → 已汙染、1 條正面＋1 條負面，一件永遠只有 2 條；最多 3 階，再轉化是整組換新 ✅。
- 3.16.0d 修正：負面不再直接抵銷正面（「附加物理」配「不造成物理」禁止）；過狠的負面重做（「無法用移動技能」→「移動技能冷卻 +50%」）✅。
- 代表詞：+30 閃避／混沌抗 −15%；技能等級 +1；擊中詛咒；保留效益；擁有關鍵天賦；負面：不造成〈屬性〉傷害、最大生命 −X%、無法回復、技能費用 +X%。共 44 條。
- 評價：被罵「太隨機、不值得賭真正好的裝」「負面常剛好廢掉正面」「掉落的災魘裝全是垃圾」；地圖災魘比裝備災魘受歡迎。
- **教訓**：負面不可直接抵銷正面；負面要「可能不影響你的 build」才有人賭；做完就鎖死＋負面隨機＝沒人拿好裝去賭。

## 5. 食魔／滅燼（Eldritch）固定詞（3.17）

- 只有頭、手、鞋、胸；每件上（灼熱總督）下（噬界者）各 1 條；6 階（次級→完美），前 4 階用餘燼／靈液直接蓋，後 2 階只能用衝突寶珠「提高一邊、降低另一邊」✅。
- 改規則型：保留效益、非詛咒光環效果、擊中曝露、恐懼／威嚇、行動速度不低於基礎。數值型：抗性、移速、冷卻。

## 6. PoE2 0.3 褻瀆（Desecrated）詞

- 骨頭通貨分部位（顎骨→武器、肋骨→防具、鎖骨→首飾、顱骨→珠寶）、三個等級（啃噬 ≤ ilvl 64、保存不限、遠古保證高階）✅。
- 用法：對稀有物加 1 條**隱藏**詞（占一格前後綴），到靈魂之井揭露、**三選一** ✅；預兆可鎖前後綴、保證血脈詞。
- 池子：285 條，大部分是該部位**正常詞池**，加三個血脈專屬詞（烏拉曼：弩砲圖騰 +1、攻擊額外連鎖、移動時多射 2 發；阿瑪納穆：胸甲護甲 +35～50%（換包裝）；庫爾加爾：魔力轉護甲、6m 外投射物 +20～30%）✅。
- 評價：「比以往接近確定性做裝」（三選一、可鎖）；上線後被 nerf；多數揭露出來仍是普通詞。
- **教訓**：賭的不是「正負」而是「好不好中」；三選一把 RNG 變成選擇。

## 7. 分類：改規則 vs 換包裝的數值

**改規則**：+1 技能等級類、額外詛咒、額外投射物／連鎖、圖騰／召喚上限、擊中觸發（詛咒、曝露、護體、恐懼）、直接給關鍵天賦、自帶輔助、保留效益／光環效果、免疫類、資源換算（魔力轉護甲）、寶石品質。

**換包裝的數值**：抗性、最大抗 +1%、移速、攻速、暴擊、附加傷害、護甲％、生命、冷卻、「對 6m 外 +X%」這種條件型數值。
