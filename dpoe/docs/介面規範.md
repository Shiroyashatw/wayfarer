# dungeonPOE 介面規範

改介面（畫面、面板、HUD、互動、動畫、說明文字的排版、CSS）時照這份。長相以 skill `impeccable` 與 `DESIGN.md` 為主（數值跟 `DESIGN.md` 不一致時改這份），互動手感照 `apple-design`；這份提供 dungeonPOE 實際在用的數值、元件、技術限制與測試尺寸（兩個 skill 都不能推翻）；操作規則在 `docs/企劃書.md` 第 9 節。（舊的《塞令老師》直式規範在 `封存/設計規範.md`，不適用。）

## 1. 平台與測試尺寸

- **桌機為主、手機為輔**。手機是**橫向**全螢幕（`body.touch`）。
- 每次改介面，四個尺寸都要截圖：
  - 桌機 **1440×900**、**1280×720**（面板不能超出畫面）。
  - 手機橫向 **844×390**、**667×375**，手機直立 **390×844**、**375×667**（`node tools/touch_check.js 寬 高 [網址]`，要先開本機伺服器；直的尺寸自動測直立操作；瀏覽器模擬時寬度小於 768 才會切成手機模式）。直立是 `body.touch.port`（`PORT()`，設定裡選，`S.orient`）。
- 遊戲邏輯只透過 `mouseWorld()` 與移動方向拿輸入，技能、戰鬥程式裡不判斷是不是手機。

## 2. 變數（`css/style.css` 開頭的 `:root`）

只用變數，不在 JS 寫死顏色或字級。

| 類 | 變數 |

| 狀態色 | `--gold`（0.2.33 起是重點白，黃色只用稀有度 `--r2`）、`--good`、`--bad`、`--warn`、`--blue`（文字用 `.c-gold`、`.c-good`、`.c-bad`、`.c-warn`、`.c-dim`） |
| 稀有度 | `--r0`（普通）、`--r1`（魔法）、`--r2`（稀有）、`--r3`（寶石青色）；框色用 `.r0`～`.r3` |
| 元素 | `--fire`、`--cold`、`--light`、`--chaos`（和 `js/data.js` 的 `ELC` 一致） |
| 字級 | `--fs-s` 12px、`--fs` 14px、`--fs-l` 18px；手機 HUD 的最小字 10px |
| 間距、圓角 | `--sp` 8px；圓角 0.2.14 起一律 2px（格子裡的道具 1px，只有球與手機圓形鍵是正圓；`--rad` 6px 已經不用） |
| 格子 | `--cell`（背包一格的邊長，`resize()` 照螢幕設定） |
| 字型 | `--font`（Noto Sans TC）；標題、按鈕的主要動作、王名用襯線 `--serif`（Noto Serif TC 700） |
| 外觀（0.2.33 鑄鐵銀框，規則在 `DESIGN.md`） | 鐵灰四階 `--s0`～`--s3`、框 `--fr-o`／`--fr`／`--fr-hi`、九宮格外框 `img/ui/frame.png`、鋼藍灰主色 `--act`／`--act-hi`（紅色只代表危險）、選中銀底 `--sel`／`--sel-ink`、標題白 `--title`、標題字 `--serif`（Noto Serif TC 900） |

地圖卡的星級顏色（藍、黃、紫、橘、紅）在 `js/maps.js` 的 `STARS`，用 `--sc` 傳進卡片。

## 4. 互動與動畫

- **按下就有回饋**：可點的元件 `:active` 縮小（`transform: scale(0.95～0.97)`）。
- **放開才執行**：手機的互動鍵、點地上的擺設都等手指放開（`click`）才開面板；按下就開的話，放開的那一下會落到剛長出來的按鈕上。
- 面板出現：`pop`（置中面板）、`inL`／`inR`（左右面板），200ms、`cubic-bezier(0.23, 1, 0.32, 1)`；動畫不擋操作。
- **減少動態**：`@media (prefers-reduced-motion: reduce)` 只淡入淡出。
- 不靠 hover 傳達資訊（手機沒有 hover）：不能按的按鈕把原因寫在按鈕上。桌機可以用滑過加速（昇華盤面），但手機要有對應的點選。
- 孔裡的寶石滑過時是唯讀說明框，貼在面板外面，不蓋住隔壁的孔。
- 不用 `backdrop-filter` 或大面積模糊（效能）。
- 世界地圖：拖曳 1:1 跟手，放開照放開前一刻的速度滑（停住才放開就不滑），鏡頭出界軟彈回；世界展開碰一下就結束；減少動態時沒有慣性、環境動畫與演出。
- 戰鬥特效用 pixelfx 序列圖（`fxs()`，`js/fxsheets.js`）；遊戲畫面上的東西畫在 canvas，不做成 DOM。

## 5. 資訊量

- 清單只放圖示＋名稱＋一行說明；詳細的放說明框。
- 數量 0、不能用、還沒開放的收起來或標 `.lock` 並說明原因。
- 能用數字或顏色代替句子就不要寫句子（▲▼、框色、星級）。

## 6. 檢查

- 改完在第 1 節的六個尺寸截圖，看：面板沒有超出畫面、主要按鈕看得到、字不小於 10px、按鈕不重疊。
- 手機跑 `tools/touch_check.js`（搖桿、技能點／拖／取消、翻滾、面板不出畫面、點道具的動作、天賦樹點兩次與兩指縮放）。
- 改一個面板以上：改前、改後各跑一次 Impeccable `critique` 或 `audit`（skill `ui-design` 寫了依大小做到哪）。

## 0.2.30 補充

- 字級下限：面板內功能字 11px；手機 HUD 的條上數字與按鍵提示 10px，不能再小。
- `--panel` 是不透明的 `--s1`。視覺方向見 `DESIGN.md` 開頭的暗石細線說明。
- 不能復原的高代價動作才用 `confirm2` 按兩次，文字要寫出代價：升滿與全部升滿花掉現有靈魂一半以上時（`gemBig`）、重置天賦、重置昇華。
- 手機橫向：要決定的東西要在第一屏（`tools/touch_check.js` 有檢查）。背包與裝備欄分頁（`LAND()`）；技能寶石、世界地圖、昇華石碑都是左右兩欄。畫面矮於 480 時技能寶石佔滿，背包用標題列的按鈕切換（`swapOn()`）。
- 狀態圖示：`combat.js` 的 `STATE`。玩家在技能列上方（`#mech`，圖示＋秒數或層數），怪物在血條上方（`drawMobStates`）。
- 召喚物（0.2.52）：受傷時頭上有小血條（`render.js` 的 `drawWolf`，大小與畫法跟怪物的一樣，友方用 `good` 綠）；等復甦時玩家狀態列多一格「復甦」（秒數＋隻數）；被魔像嘲諷的怪頭上是嘲諷圖示。都沿用現有元件，沒有新的。圖騰與砲塔圖騰（0.2.53）受傷時頭上也是同一種小血條（`drawUnit`）。
- 蓄力條（0.2.54，`render.js` 的 `chargeBar`）：蓄力技能按住時畫在主角腳下，一段一格（14×4、間隔 2）；正在蓄的那格跟著時間長（`locked-ink`），滿一格變亮（`bronze-bright`），剛滿的那一下與全滿是最亮的 `title-gold`。不用黃色（黃色只給稀有度），沒有位移動畫，減少動態時不用另外處理。
- 蓄力的手勢（0.2.54）：桌機按住那一格的鍵、放開出手；手機按下技能鍵就開始蓄（按下就有回饋，不等放開），拖曳＝手動瞄準，拖回按鈕上＝取消（瞄準線變紅，跟其他技能一樣）並退回魔力。
