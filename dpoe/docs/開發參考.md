## 0.1 武器與技能體系（2026-11-02 定案）

依據：`PoE武器與基底.md`、`PoE技能體系.md`。原則：**每種武器＝一種玩法身分**，技能照「一招製造狀態、另一招收割」串起來；重複的體系合併，不做兩套做法。

**武器 15 種＋徒手**（0.2.12：**單手、雙手是同一類**，劍、斧、錘各有單手與雙手基底，技能共用；雙手是基底的屬性，決定能不能拿副手、能不能雙持），全部列進武器表、基底照 PoE2 資料做齊。技能分兩批：PoE2 已開放的 10 種先照 PoE2 的技能組做；還沒開放的 8 種用 PoE1 的同類技能加上自己設計補。原本的刀、野太刀、短刀拿掉。

| 武器 | 體系（身分） |
| --- | --- |
| 錘（單手、雙手） | 重擊、猛擊、餘震、碎裂地面、破甲、沉重暈眩 |
| 細杖 | 連擊、力量球、冰晶 |
| 長矛 | 近戰與投擲雙模、招架與受招架（長矛自己的技能）、狂怒球 |
| 弓 | 元素箭、毒氣雲（可引爆）、可重複射擊、印記 |
| 十字弓 | 彈藥、榴彈、迫擊砲、砲塔圖騰 |
| 劍（單手、雙手） | 物理連斬（快、多段、蓄段數一次放出；跟錘的慢而重單發區分）、元素打擊（劍招附上元素）、幻影（召出劍士分身一起出招） |
| 斧（單手、雙手） | 擲斧、流血、戰吼 |
| 鏈錘 | 蓄力引導、旗幟 |
| 匕首 | **御劍**（刃類法術，參考修仙：召出飛劍環繞、疊層、一次射出；劍陣插地再引爆）、**伏擊**（翻滾或完美閃避後瞬移背刺、必定暴擊）、暴擊為主軸 |
| 爪 | 快速多段、擊中回血回魔、致盲 |
| 陷阱器 | 陷阱、地雷、機關（踩到才爆） |
| 護符（變身） | 熊、狼人、飛龍、植物、風暴、狼（夥伴） |
| 長杖、法杖 | 元素法術、混沌、詛咒、屍體與幽魂 |
| 權杖 | 光環、骷髏、魔像、傳令 |
| 不限武器 | 法術（元素法術、灌注與殘留物；烙印、咒符之力（法印）0.2.11 刪掉，不做）、詛咒、印記、觸發與能量、圖騰 |

**異常不算體系**：每種武器都會有幾招帶異常（點燃、冰緩、感電、流血、中毒、破甲…），表上只寫「整套玩法圍繞它」的（例：斧＝流血）。

副手（2026-11-02，2026-11-06 改）：**輕盾是盾的一種**（護甲低、有閃避，不綁技能），每面盾都有格擋值，所有單手武器都能配；**招架改成長矛自己的技能**，不靠副手。法器配單手法系武器（法杖、權杖）。箭袋只配弓。**權杖可以放副手**，配任何單手武器（例：單手錘＋權杖＝近戰帶光環）。雙手武器不能拿副手（弓可配箭袋）。**雙持**：爪、匕首、單手的劍、單手的斧可以兩手各拿一把同類武器，攻擊時兩手輪流出、攻擊速度更快；錘、長矛、鏈錘、法杖、權杖不能雙持。

**防具與飾品**（照 `PoE武器與基底.md` 第 3、4 節）：每個部位（頭、胸、手、腳）分護甲、閃避、能量護盾三系，再加護甲／閃避、護甲／護盾、閃避／護盾三種混合，每部位每系 6 個基底，防禦到階級 12 凍結，階級 12 起的胸甲靠固定詞分流（企劃書第 5 節）。戒指、項鍊一個基底對一條固定詞（抗性、生命、魔力、攻擊附加、施法速度、精魂…）；腰帶 1～3 格護符欄＋一條固定詞（生命、魔力、藥劑、護甲、門檻）。

**不做**：變異（Vaal）技能；PoE1 的異變寶石（每顆技能都有異變版，大多很爛）——它的概念併進族裔寶石。

**輔助寶石**
- 照 PoE2 0.3 以後：每顆輔助有一個分類，**同一分類不能插在同一個技能上**，可以跨技能重複。
- 分級：I、II 在生成視窗做（II 要求的角色等級比較高）；**最高一級＝覺醒**，只從特定王掉落（之後做那個機制時一起做）。I、II、覺醒同一分類。
- **族裔寶石**：插上去會改變技能的玩法（取代異變寶石的概念），全角色同名限一顆；先做 5～6 種試水溫，只從特定機制掉落。

**技能用的底層新機制**：✅ 0.2.10 已全部做進 `js/mech.js`，規則在企劃書 7.3。

## 1. 數值量級（照 PoE2，已依我們的樹密度下修）

細節：`PoE天賦參考.md`、`天賦下修對照.md`。

- **小點**：通常一點一條詞，可以兩條（PoE2 小點約 1/6 有兩條，2553／507）。傷害類 +3%（PoE2 是 8～12%，我們的樹點得到的比例是 PoE2 的 2.3 倍，所以壓更低）、攻擊速度 +1%、暴擊率提高 +6%、暴擊傷害加成 +4%、護甲／閃避／能量護盾 +8%。
- **大點**：主效果約小點的 2.5～3 倍，或「主效果＋條件／代價」。
- **生命**：不給 %（大點最多 3%）；生命靠裝備與幹道上的基礎能力點（+10 生命）。
- **更多（more）**：天賦大點幾乎不給（PoE2 984 個大點只有 4 個），留給輔助、昇華、基石。
- **直接減傷**：不給（只有召喚物可以有）。
- **基石**：「30～50% 更多／更少」一定配一個明顯的代價，放在路線末端。

## 2. 天賦樹的結構（防止沿同一主題一路點爆）

細節與 PoE2 的實測數字：`PoE天賦結構.md` 第 5 節（18 條規則）。

**形狀＝幹道＋小口袋**：
- **幹道**：過路點（我們用基礎能力點：+10 生命、+10 魔力、+20 護甲、+20 閃避、+8 能量護盾）組成，像十字路口，約佔全樹 16%。走到一個大點的路上約 2/3 是過路點。
- **叢集**：沿幹道每 1～2 個過路點岔出一個；一個叢集 ＝ 2～6 小點 ＋ 1～2 大點，平均約 5 點。小點至少 80% 同一條詞；大點 75% 是同主題放大、25% 是轉折（接到隔壁主題或加條件、代價），放在叢集最裡面。64% 的叢集是死路（點完退回幹道），叢集之間不直接相連。
- **主題排列**：同主題叢集至少隔 3 步，平均 5 步以上；同主題相連的點平均 ≤ 3、最多 12。用「區域權重抽樣＋距離排斥」，不是固定輪換。
- **區域**：6 個起點各佔 60°。集中型主題（護甲、格擋、閃避、能量護盾、投射物、法術、召喚、陷阱、圖騰、各武器、精魂光環）綁在 1～2 區；通用主題（生命、暴擊、元素、攻擊速度、範圍、魔力冷卻）每區都有。由內到外：通用防禦 → 主體 → 專精（武器、單元素、召喚）與基石。
- **規模（1643 點時）**：約 270 個叢集、380 個大點、14 個基石、260 個過路點。
- **驗收**（產生器跑完要量）：叢集平均 3～4 小／1.3～1.5 大、死路 55～70%、大點在最遠端 ≥ 75%、同主題連續平均 ≤ 3／90% ≤ 6／最大 ≤ 12、最近同主題叢集 ≥ 5 步、起點到第一個大點 4～5 步。

**樹缺的**：每種武器類別都要有自己的專精叢集（PoE2「持某武器時」的大點約是通用大點的 1.5 倍）。主題清單要等第 2、3 層定了才定。

## 3. 昇華的設計（0.2.25 起不分職業）

細節、PoE1／Phrecia／PoE2 全部昇華與例子：`PoE昇華參考.md`。現在的昇華在企劃書 7.4。

**不再有職業**：只有一位主角，**直接選一個昇華**（藏身處的昇華石碑，免費換、點數退回）。昇華不限制武器，但可以有 1～2 個「綁裝備」的大點（例：持錘時、副手拿盾時）。

**骨架**：8 點＝4 個大點＋4 個小點（開局 2 點，第一次打倒第 6、12、16 階的王各 +2）。**每個昇華的結構可以不一樣**（三選一、二選一、單獨一條），**不做終極大點**，但一律照 PoE「**小 → 大 → 小 → 大**」：每個大點前面一定有自己的小點、小點後面只接大點，分支分出去也是「小 → 大」，不能大點接大點、兩個小點連在一起。這樣不會逼玩家拿某個點。三選一／二選一是「選擇組」，同組只能拿一個。小點給後面那個大點相關的單一數值。點之前檢查「還能補成剛好 4 大 4 小」（`tools/check.js` 驗：一小一大交錯、所有合法組合沒有必拿的點、亂點 2000 次）。

**好的昇華大點用這六種手法**（每個昇華至少要有一個 A、B 或 E，不能整棵都是 +x%）：

| 手法 | 意思 | PoE 例子 |
| --- | --- | --- |
| A. 新資源／新機制 | 一定是既有數值的另一種讀法 | 地獄火（反過來的魔力）、黑暗（延後扣的生命）、靈光（走路生成、攻擊消耗） |
| B. 改寫底層規則 | 基石式的取捨 | 有護盾時生命不變、物理一半轉火、毒疊更多層但更短 |
| C. 綁一種玩法並質變 | 讓某體系出現新行為 | 異常必定觸發、冰凍感電變成地面、圖騰數量 |
| D. 給技能 | 用通用效果包成按鈕 | 時間凍結、顯化武器、三個高等光環 |
| E. 更多但附代價 | 好處和代價一起寫在同一點 | 傷害更多 40% ↔ 受到的傷害提高；只能穿普通胸甲 |
| F. 特殊結構 | 三選一、多一個欄位 | 季節誓約、多一個護符欄 |

**我們的限制**：
- 每個大點都要寫它用到哪個底層概念；底層沒有的，先加進底層（企劃書 7.2、7.3）才能用。0.2.25 為第一批補了格擋值、暴擊弱點、依防禦給附加傷害、投射物飛行距離、全域連鎖、幻影用主角的攻擊技能、順風的新來源。0.2.26 第二批補了地獄火資源、承受轉換、完美閃避判定時間、咒爆、點燃傳染、火焰曝曬、閃電轉火。
- 機率觸發一律用熵值（設計原則第 4 節）。
- **體系本身綁武器的昇華可以例外**（2026-11-07）：千機的彈藥與榴彈只有十字弓、詭雷師的陷阱與地雷只有陷阱器，所以這兩個昇華實際上綁武器。大點照樣寫技能類型（彈藥技能、榴彈技能、陷阱技能），不寫「持某武器時」。
