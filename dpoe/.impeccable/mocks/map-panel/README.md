# 地圖台改版 mock（暫停）

2026-11-06 使用者決定暫停：地圖系統要改成 PoE2 式大地圖，階級 1～16 會淘汰，階級尺和開圖流程可能整個換掉。卡片的呈現可能保留，等規格定案再決定。遊戲裡的地圖台維持原樣，這裡只留設計成果。

## 怎麼看

在 `dpoe/` 底下跑 `py -m http.server 8026`，開 `http://localhost:8026/.impeccable/mocks/map-panel/index.html`（加 `&hunt` 看狩獵之血預留的位置）。用獨立存檔槽 `?p=mock`，不載入雲端模組。`mock.js` 只覆寫 `devHTML`，規則走現有函式。

改前改後截圖在 Claude Artifact「dungeonPOE 三面板改版」第 1 版，檔名 `尺寸_map_b.jpg`（改前）與 `尺寸_map_a.jpg`（改後）。

## 做法

- **階級尺**：1～16 一排直接點，鎖住的虛線；手機橫向捲動，自動捲到選中的那格。（大地圖定案後大概用不到）
- **卡片清單**：依物品數量排序，每張寫獎勵、費用、致命詞的短名，看不用點就能篩掉不想打的卡。
- **右欄**：選中的卡分致命、中等、溫和列出全部地圖詞，開門鈕固定在清單外面。桌機滑過就預覽。
- **手機**：直立清單在上、開門鈕在拇指區；橫向左右兩欄。
- **預留**：狩獵之血進度條在階級尺下面，生肖王卡排在清單最上面。

## 重啟時要重新決定

1. **預選哪一張**：mock 預選買得起的最肥一張；另一個選項是預選最便宜的，避免連按開到高危險卡。
2. **開門後要不要自動走進去**：開門直接進圖，每張少 1 步，但會動到藏身處流程。
3. **致命詞短名**：正式做要放進 `MAPMOD` 的 `s` 欄，並在 `check.js` 檢查每條致命詞都有短名。

## 已知問題

原本的地圖台在 844×390 等手機橫向尺寸，地圖詞可能只看得到前幾條，卡片文字會換行。mock 的左右兩欄版面解決了這點，暫停後維持原樣。
