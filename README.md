# 塞令老師

4 人一場的**背包自動對戰**網頁遊戲：每回合在商店買道具、擺進背包、合成升階，戰鬥完全自動；對手是其他玩家在同一回合留下的背包快照。

- 線上遊玩：https://shiroyashatw.github.io/wayfarer/
- 目前版本：v0.1.3（[更新紀錄](CHANGELOG.md)）
- 企劃書：[docs/企劃書.md](docs/企劃書.md)（0.3 以前「漫步勇者」的企劃在 [docs/舊企劃書_漫步勇者.md](docs/舊企劃書_漫步勇者.md)）
- 建議用手機直式開啟

## 目前內容

- 4 人一場、生命 40；回合前短後長：野怪（1-1 開打前用 10 金買初始構築）→ 菁英 → 第 2 階段對戰與野怪穿插、菁英首領 → 對戰為主，每階段第 4 輪是菁英
- 背包從 3×3 升到 6×6，道具有形狀（商店、說明都有形狀小圖）、可以旋轉（選中的道具右上角 ↻）；拖曳擺放
- 每局開打前選職業（三選一、可刷新一次，13 種），照職業規劃流派
- 111 種道具（各系都有 5★；雙手武器、各種形狀、開戰丟出的藥劑）＋ 312 個職業核心（每個職業 12 個專屬核心＋12 個副核心）
- 異常狀態：燃燒、中毒、流血、破甲、凍結、暈眩、虛弱、致盲（武器、防具、盾、飾品與輔助道具、藥水、寵物），1～5★；3 件相同合成升階（最多 Ⅲ 階、多一條詞綴）；5★ 道具開一條隨機詞綴
- 相鄰、同一排、全背包的加成；8 個職業核心決定流派（劍聖、統帥、獵手、煉金、元素、死靈、守護、刺客）
- 完全自動的戰鬥（背包格子跑冷卻條）：開戰封鎖／降階敵人武器、冷卻、暴擊、格擋、燃燒、中毒、凍結、暈眩、吸血、疲勞；固定亂數可重播
- 快照對戰（Supabase）：不用等人上線；沒有真人快照時由機器人補位
- 點左上角頭像看角色數值（生命、護甲、閃避、暴擊、每把武器的每秒傷害）
- 牌階（鐵牌～菁英，各分一二三，前 5 場定級）、戰績、道具圖鑑、10 種頭像（名字隨機，可以自己取）；Supabase 雲端存檔（遊客或信箱帳號）

## 開發

純靜態網頁，不需要建置。

```bash
python3 -m http.server 8000
```

檔案結構與開發規則見 [CLAUDE.md](CLAUDE.md)。快照對戰的資料表在 `supabase/migrations/20261022000000_serling_ghosts.sql`（在 Supabase 的 SQL Editor 執行一次；沒建的話遊戲會自動用機器人對手）。前端只使用 anon key。

地圖相關的舊程式（走路、城鎮、地城、天賦樹、昇華…）已在 0.1.0 移除，可以在 git 歷史（0.3.46 以前）找到。
