# 漫步勇者

台灣妖怪題材的手機肉鴿網頁遊戲：一局 15～20 分鐘，三章節點地圖一路往上打，用技能石、輔助寶石、詞綴裝備、天賦與昇華組出這一局的 Build。

- 線上遊玩：https://shiroyashatw.github.io/wayfarer/
- 目前版本：v0.1.0（[更新紀錄](CHANGELOG.md)）
- 企劃書：[docs/企劃書.md](docs/企劃書.md)
- 建議用手機直式開啟

## 目前內容

- 三章：山林、城市・夜市、冥府・魔霧；每章 10 層節點地圖（戰鬥、菁英、事件、商店、休息、寶箱、首領）
- 首領：台灣鬼怪（魔神仔、虎姑婆、林投姐…）、十二生肖、山海經四凶、海盜王、七宗罪之王、亡靈王、燭龍、閻羅王
- 勝利獎勵三選一、升級天賦三選一（含基石）、首領之後昇華三選一
- 8 個角色（昇華職業）、約 130 種技能石、輔助寶石、PoE 式詞綴裝備與通貨製作
- 13 個台灣民俗事件（土地公、紅包、媽祖遶境、夜市、孟婆湯…）
- 局外：魂晶解鎖角色與升級、契靈祈願、每日挑戰
- Supabase 雲端存檔：遊客匿名登入，或用信箱註冊／登入並取得玩家編號

走路版（0.3.52 以前，以真實台灣地圖為舞台）的紀錄在 `docs/archive/`。

## 開發

純靜態網頁，不需要建置。

```bash
python3 -m http.server 8000
```

檔案結構與開發規則見 [CLAUDE.md](CLAUDE.md)。雲端存檔使用 Supabase `saves` 資料表（RLS，只能讀寫自己的存檔），玩家編號在 `profiles`，結構在 `supabase/migrations/`。網頁裡的 Supabase 金鑰是公開用的 anon key。
