# 漫步勇者

以真實台灣地圖為舞台的回合制 RPG 網頁 demo。出門走路是冒險，在家經營據點也能推進。

- 線上遊玩：https://shiroyashatw.github.io/wayfarer/
- 目前版本：v0.1.2
- 建議用手機直式開啟

## 目前內容

- 遊戲風格地圖（台中車站周邊，道路依真實位置近似）
- 迷霧探索、晝夜與視線範圍、提燈
- 菁英怪、寶箱、限時事件（流浪商人、魔物裂隙、祝福泉、懸賞）
- PoE 式詞綴裝備、7 種通貨製作、94 節點天賦樹
- 主據點、分支據點與遠征
- Supabase 匿名登入與雲端存檔

## 技術

單一 `index.html`，不需要建置步驟。雲端存檔使用 Supabase（`saves` 資料表，啟用 RLS，每位玩家只能讀寫自己的存檔）。網頁裡的 Supabase 金鑰是公開用的 anon key。
